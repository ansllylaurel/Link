Для настройки Путь к файлу доступны следующие шаблоны:

Шаблон Описание
%ИмяОтчета% Наименование отчета (Справочник.Отчеты.Наименование)
%КраткоеИмяОтчета% Краткое наименование отчета (Справочник.Отчеты.КраткоеНаименование)
 
%ИмяОрганизации% Наименование организации счета ДУ
%ВидДоговора% ДУ или НПФ
%ИмяКлиента% Наименование счета ДУ
%ИмяКлиентаБезНПФ% Наименование счета ДУ без первых 4х смволов, если это "НПФ "
%НомерДоговора% Номер договора доверительного управления
%ДатаДоговора_ДФ=dd_MM_yyyy% Дата заключения договора, приведенная к форматной строке. См. описание шаблона %ФорматДаты_ДФ=dd_MM_yyyy%
%КраткоеНаименованиеКлиента% Краткое наименование клиента по уставу, либо Фамилия И.О. для физ. лиц
%КраткоеНаименованиеКлиентаБезОПФ% То же, что и %КраткоеНаименованиеКлиента%, но без организационно-правовой формы (ОПФ), т.е. без АО, ООО, НПФ и пр.
%ИИС% "Клиенты ИИС\" для вида договора "Индивидуальный инвестиционный счет", для прочих видов договоров не заполняется. Используется для создания отдельной папки по договорам ИИС
%Лицензия% "НПФ" или "ДУ" вид деятельности из лицензии 
 
%Периодичность% Периодичность в формате "Ежедневные" и т.д.
%КаталогПоПериодичности% Каталог и подкаталог по периодичности
%ПредставлениеПериодичности% Представление периодичности для имени файла
%ПредставлениеПериода% Представление бухгалтерского периода. См. в РаботаСБухгалтерскимиОтчетамиКлиентСервер.ПолучитьПредставлениеПериода
%Год% Год отчетной даты
%Квартал% Квартал отчетной даты
%Месяц% Месяц отчетной даты
%Неделя% Неделя отчетной даты
%День% День отчетной даты
%ФорматДаты_ДФ=dd_MM_yyyy% Отчетная дата, приведенная к форматной строке. "ДФ=dd_MM_yyyy" может быть заменено на любую форматную строку даты. 
Для формирования форматной строки можно воспользоваться конструктором форматной строки из контекстного меню поля Значение. 
Созданную таким образом форматную строку необходимо скопировать и вставить в шаблон. 
Примеры шаблонов формата даты: 
%ФорматДаты_ДЛФ = 'DD'% 
%ФорматДаты_ДЛФ = 'DDT'% 
%ФорматДаты_ДФ = 'dd/MM/yy'% 
%ФорматДаты_ДФ = 'yyyy-MM-dd'% 
%ТекущаяДата_ДФ=yyyy-MM-dd% Дата формирования отчета, приведенная к форматной строке. См. описание шаблона %ФорматДаты_ДФ=dd_MM_yyyy% 
Необходимо учесть, что формирование пути к файлу осуществляется в момент заполнения таблицы отчетов в обработке Формирование отчетности, а не в момент фактической выгрузки отчетов в файл 


Примеры: 
Путь к файлу: \\ОТЧЕТНОСТЬ КЛИЕНТАМ\_Ежедневные\2017\Сентябрь\20170913\Клиент (Периодический отчет управляющего) 20170913.xls
Шаблон: \\ОТЧЕТНОСТЬ КЛИЕНТАМ\%Периодичность%\%Год%\%КаталогПоПериодичности%\%ИмяКлиентаБезНПФ% (%ИмяОтчета%) %ПредставлениеПериодичности%.xls
Путь к файлу: \\Бухгалтерская_отчетность\Отчеты НПФ 2017\Клиент\Август\Анализ сч 479 за 9 месяцев 2017 г..xls
Шаблон: \\Бухгалтерская_отчетность\Отчеты %ВидДоговора% %Год%\%ИмяКлиентаБезНПФ%\%Месяц%\%ИмяОтчета%%ПредставлениеПериода%.xls
Путь к файлу: \\ОТЧЕТНОСТЬ КЛИЕНТАМ\Отчетность Лицензия ДУ\Клиенты ИИС\Ежедневные\2017\Сентябрь\20170913\Клиент (Периодический отчет управляющего) 20170913.xlsx
Шаблон: \\ОТЧЕТНОСТЬ КЛИЕНТАМ\Отчетность Лицензия %Лицензия%\%ИИС%%Периодичность%\%Год%\%КаталогПоПериодичности%\%ИмяКлиентаБезНПФ% (%ИмяОтчета%) %ПредставлениеПериодичности%.xls
