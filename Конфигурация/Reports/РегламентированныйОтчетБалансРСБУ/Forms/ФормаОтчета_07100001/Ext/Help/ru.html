Параметры баланса. Могут относиться как к организации, так и к счету ДУ. Приоритетным является параметр, указанный для счета ДУ. Если он не задан, тогда используется параметр для организации при его наличии или значение по умолчанию:
1. "Формировать от УК":
 ДА  - в шапке проставляются реквизиты управляющей компании (вариант УКПИ)
 НЕт - в шапке проставляются реквизиты реквизиты клиента (вариант РЭМа)
2. "Выводить номер приказа": в шапке выводится номер приказа, утверждающий отчетную форму
3. "Код по ОКОПФ"
4. "КОД по ОКФС"
5. "Определять долгосрочность 79.3 по дате расторжения договора ДУ":
 ДА  - если до даты расторжения меняя года, то догосрочные, иначе краткосрочные вложения
 НЕТ - краткосрочные вложения
6. "Строка для депозитных вкладов (1240/1250)" - строка, в которую будут выведены депозиты. Возможные варианты значений: 1240 или 1250. При необходимости указать другую строку потребуется доработка. По умолчанию - 1250
7. "Строка для % по депозитным вкладам (1230/1260)" - строка, в которую будут выведены проценты по депозитным вкладам. Возможные варианты значений: 1230 или 1260. При необходимости указать другую строку потребуется доработка. По умолчанию - 1230
8. "Строка для купона начисленного на 76 счете (1230/1260)" - используется, если начисленный купон отражается на счете учета взаморасчетов. Возможные варианты значений: 1230 или 1260. При необходимости указать другую строку потребуется доработка. ПО умолчанию - 1230
9. "Строка для купона уплаченного на 76 счете (1230/1260)" - используется, если уплаченный при покупке купон отражается на счете учета взаморасчетов. Возможные варианты значений: 1230 или 1260. При необходимости указать другую строку потребуется доработка. По умолчанию - 1230
