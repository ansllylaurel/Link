Инструкция на случай изменения формата файла со ставками.

Если Центральный Банк изменит формат файла со средневзвешенными ставками по кредитам / депозитам, на почту придёт сообщение об ошибке вида:

Зарегистрирована новая ошибка № 000003497 от 08.06.2020 21:00:03 регламентного задания Импорт средневзвешенных процентных ставок:
Файл со средневзвешенными ставками По депозитам по группе банков 'Все банки РФ' страница: ставки_долл_США не соответсвует шаблону!

Это будет означать, что в файле по депозитам по всем банкам изменилась шапка на закладке ставки_долл.США. Файл при этом будет сохранён в базу Externals и его можно открыть дополнительной  обработкой «Открытие фалов из Externals». Имена файлов:

1.       deposits.xlsx – по депозитам по всем банкам
2.       deposits_30.xlsx – по депозитам по 30 крупнейшим банкам.
3.       loans_nonfin.xlsx – по кредитам по всем банкам.
4.       loans_nonfin_30.xlsx – по кредитам по 30 крупнейшим банкам.

Для корректной загрузки ставок необходимо изменить шаблон шапки в макете обработки. Макеты соответствуют файлам:

1.       deposits.xlsx              – ШаблонВсеБанкиРФПоДепозитам
2.       deposits_30.xlsx        – ШаблонКрупнейшие30БанковПоДепозитам
3.       loans_nonfin.xlsx        – ШаблонВсеБанкиРФПоКредитам
4.       loans_nonfin_30.xlsx  – ШаблонКрупнейшие30БанковПоКредитам

А их области соответствуют закладкам в файлах.

Чтобы изменить область необходимо:

1.       Посмотреть в каком поле находится "маркер" в области – поле, фон которого имеет цвет Красный (255, 0, 0). По этому полю обработка решает, где вертикально начинаются ставки.
2.       Убедиться, что область по высоте соответствует шапке в файле. При необходимости добавить или удалить строки в область.
3.       Удалить данные области. Скопировать шапку из файла. Вставить в область.
4.       У поля "маркера" установить красный цвет (255, 0, 0).
5.       Сохранить обработку, повторно загрузить ставки, указав дату закгрузки, в которую была ошибка.
