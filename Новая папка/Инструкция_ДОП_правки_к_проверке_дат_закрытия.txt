ПРАВКА A (КРИТИЧЕСКАЯ). Серверная проверка расторжения договора должна брать НОВУЮ дату
=====================================================================

Проблема:
  В ПередЗаписью регистра «УсловияДоговоровОбщие» нельзя вызывать проверку,
  которая читает ДатаРасторжения из БД (она ещё не записана).
  Иначе проверка фактически работает по СТАРОЙ дате из базы.

Где правим:
  РегистрСведений: УсловияДоговоровОбщие
  Модуль набора записей: `ПередЗаписью` + процедура `КонтрольДатыЗакрытияДепозитарныхСчетов`

Что сделать:
  1) Оставить вызов `КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ);` в `ПередЗаписью` (он нужен).
  2) ЗАМЕНИТЬ тело процедуры `КонтрольДатыЗакрытияДепозитарныхСчетов` на вариант с `ЭтотОбъект.Выгрузить()`.

КОД ДО (пример «плохого» варианта, который проверяет старые данные):
------------------------------------------------------------
Процедура КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ)
	
	ПроверенныеДоговоры = Новый Соответствие;
	
	Для каждого Запись Из ЭтотОбъект Цикл
		
		Если Не ЗначениеЗаполнено(Запись.Договор) Тогда
			Продолжить;
		КонецЕсли;
		
		Если Не ЗначениеЗаполнено(Запись.ДатаРасторжения) Или Запись.ДатаРасторжения = ДАТАВРЕМЯ(1, 1, 1) Тогда
			Продолжить;
		КонецЕсли;
		
		Если ПроверенныеДоговоры.СодержитКлюч(Запись.Договор) Тогда
			Продолжить;
		КонецЕсли;
		
		ПроверенныеДоговоры.Вставить(Запись.Договор, Истина);
		
		// ПЛОХО: внутри общего модуля ДатаРасторжения берётся из БД, а не из текущего набора записей
		РаботаСИсполнителями.ПроверитьДатыЗакрытияДочернихЭлементов(Запись.Договор, Отказ);
		
	КонецЦикла;

ПРАВКА B. Интерактивный отбор по дате: год не должен превращаться в «2 026»
=====================================================================

Проблема:
  При конкатенации числа со строкой в некоторых настройках форматирования
  год 2026 превращается в строку "2 026" (с разделителем тысяч, часто неразрывный пробел),
  и строка условия становится невалидной:
    ... ДАТАВРЕМЯ(2 026, 4, 18) ...
  Ошибка компиляции/разбора: «Ожидался символ ')'».

Решение:
  При сборке строки условия форматировать Год/Месяц/День без группировки разрядов:
    Формат(Год(...), "ЧГ=0")

Где правим (2 места):

1) РегистрСведений: УсловияДоговоровОбщие
   Форма записи: ФормаЗаписи
   Модуль формы: процедура `ДатаРасторженияПриИзменении`

КОД ДО:
------------------------------------------------------------
Отбор = "ДатаЗакрытия = ДАТАВРЕМЯ(1, 1, 1) ИЛИ ДатаЗакрытия > ДАТАВРЕМЯ("
	+ Год(Запись.ДатаРасторжения) + ", " + Месяц(Запись.ДатаРасторжения) + ", " + День(Запись.ДатаРасторжения) + ")";
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
Отбор = "ДатаЗакрытия = ДАТАВРЕМЯ(1, 1, 1) ИЛИ ДатаЗакрытия > ДАТАВРЕМЯ("
	+ Формат(Год(Запись.ДатаРасторжения), "ЧГ=0") + ", "
	+ Формат(Месяц(Запись.ДатаРасторжения), "ЧГ=0") + ", "
	+ Формат(День(Запись.ДатаРасторжения), "ЧГ=0") + ")";
------------------------------------------------------------

2) Справочник: ДепозитарныеСчета
   Форма элемента: ФормаЭлемента
   Модуль формы: функция `ПолучитьОтборПоДатеЗакрытия`

КОД ДО:
------------------------------------------------------------
Возврат "ДатаЗакрытия = ДАТАВРЕМЯ(1, 1, 1) ИЛИ ДатаЗакрытия > ДАТАВРЕМЯ(" 
	+ Год(ДатаЗакрытия) + ", " + Месяц(ДатаЗакрытия) + ", " + День(ДатаЗакрытия) + ")";
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
Возврат "ДатаЗакрытия = ДАТАВРЕМЯ(1, 1, 1) ИЛИ ДатаЗакрытия > ДАТАВРЕМЯ(" 
	+ Формат(Год(ДатаЗакрытия), "ЧГ=0") + ", "
	+ Формат(Месяц(ДатаЗакрытия), "ЧГ=0") + ", "
	+ Формат(День(ДатаЗакрытия), "ЧГ=0") + ")";
------------------------------------------------------------

ПРАВКА C. В обработчиках ПриИзменении нельзя вызывать ЭтотОбъект.Прочитать()
=====================================================================

Проблема:
  В ПриИзменении пользователь вводит дату, запись ещё не сохранена.
  Вызов `ЭтотОбъект.Прочитать()` перечитает данные из БД и сбросит введённое значение.

Где правим (2 места):

1) РегистрСведений: УсловияДоговоровОбщие → ФормаЗаписи → Модуль
   Процедура `ДатаРасторженияПриИзменении`

КОД ДО:
------------------------------------------------------------
РаботаСИсполнителями.ЗакрытьДеревоЭлементов(...);
ЭтотОбъект.Прочитать();
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
РаботаСИсполнителями.ЗакрытьДеревоЭлементов(...);
// без ЭтотОбъект.Прочитать();
------------------------------------------------------------

2) Справочник: ДепозитарныеСчета → ФормаЭлемента → Модуль
   Процедура `ПодтвердитьИЗакрытьДочерниеЭлементы`

КОД ДО:
------------------------------------------------------------
РаботаСИсполнителями.ЗакрытьДеревоЭлементов(...);
ЭтотОбъект.Прочитать();
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
РаботаСИсполнителями.ЗакрытьДеревоЭлементов(...);
// без ЭтотОбъект.Прочитать();
------------------------------------------------------------

ВАЖНО:
  В `КомандаЗакрытьДоговор` (на форме элемента депозитарного счета) `ЭтотОбъект.Прочитать()` можно оставить,
  потому что там перед закрытием идёт сохранение формы (`ЗаписатьФорму`).
