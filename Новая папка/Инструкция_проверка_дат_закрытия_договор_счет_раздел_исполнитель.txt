ИНСТРУКЦИЯ: проверка дат закрытия договор/счет/раздел/исполнитель (внести вручную в Конфигураторе)
Дата: 2026-04-17

Цель
-----
1) Серверная проверка при записи: дата закрытия/расторжения дочерних элементов не должна быть позже родительской; если родитель закрывается — дочерние не должны оставаться «не закрыты».
2) Интерактивно: при изменении даты расторжения договора (в форме записи регистра) и при изменении даты закрытия раздела счета запрашивать подтверждение закрытия подчинённых элементов и показывать дерево закрываемых элементов.

Важно про «признак не закрыт»
---------------------------
В конфигурации уже используется соглашение: ДАТАВРЕМЯ(1, 1, 1) = «не закрыт» (см. запросы/отборы в общем модуле РаботаСИсполнителями).


=====================================================================
ИЗМЕНЕНИЕ 1. Серверная проверка при записи расторжения договора
=====================================================================

Где в конфигураторе:
  РегистрСведений: УсловияДоговоровОбщие
  Модуль набора записей (ПередЗаписью)

Что меняем:
  - В процедуру ПередЗаписью(Отказ, Замещение) добавляем вызов КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ)
  - Добавляем новую процедуру КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ)

Код ДО (фрагмент был таким):
------------------------------------------------------------
Процедура ПередЗаписью(Отказ, Замещение)
	
	КонтрольДатыЗакрытияБанковскихСчетов(Отказ);	
	
	Справочники.Договоры.КонтрольПериодаУсловийДопСоглашения(ЭтотОбъект, Отказ);
	
	УниверсальныеМеханизмы.ЗаполнитьОрганизациюИзВедущегоИзмерения(ЭтотОбъект, "Договор");
	
КонецПроцедуры
------------------------------------------------------------

Код ПОСЛЕ (заменить фрагмент на этот):
------------------------------------------------------------
Процедура ПередЗаписью(Отказ, Замещение)
	
	КонтрольДатыЗакрытияБанковскихСчетов(Отказ);	
	КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ);
	
	Справочники.Договоры.КонтрольПериодаУсловийДопСоглашения(ЭтотОбъект, Отказ);
	
	УниверсальныеМеханизмы.ЗаполнитьОрганизациюИзВедущегоИзмерения(ЭтотОбъект, "Договор");
	
КонецПроцедуры

Процедура КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ)
	
	// Депозитарные счета / разделы / исполнители не должны закрываться позже расторжения договора.
	// Проверку делаем общим механизмом (он же используется в формах закрытия через дерево).
	
	Если Отказ Тогда
		Возврат;
	КонецЕсли;
	
	ПроверенныеДоговоры = Новый Множество;
	
	Для каждого Запись Из ЭтотОбъект Цикл
		
		Если Отказ Тогда
			Возврат;
		КонецЕсли;
		
		Если Не ЗначениеЗаполнено(Запись.Договор) Тогда
			Продолжить;
		КонецЕсли;
		
		Если Не ЗначениеЗаполнено(Запись.ДатаРасторжения) Или Запись.ДатаРасторжения = ДАТАВРЕМЯ(1, 1, 1) Тогда
			Продолжить;
		КонецЕсли;
		
		Если ПроверенныеДоговоры.Содержит(Запись.Договор) Тогда
			Продолжить;
		КонецЕсли;
		
		ПроверенныеДоговоры.Добавить(Запись.Договор);
		
		РаботаСИсполнителями.ПроверитьДатыЗакрытияДочернихЭлементов(Запись.Договор, Отказ);
		
	КонецЦикла;
	
КонецПроцедуры
------------------------------------------------------------

Примечание:
  Проверка использует уже существующий общий модуль:
    ОбщиеМодули → РаботаСИсполнителями → функция ПроверитьДатыЗакрытияДочернихЭлементов(Объект, Отказ)
  Она уже проверяет «договор → депозитарные счета» (и часть других веток).

КОНТРОЛЬ (чтобы понять, что всё внедрено правильно)
=====================================================================
1) Попробуйте установить дату расторжения договора (через запись регистра УсловияДоговоровОбщие):
   - если у договора есть счета/разделы/исполнители «не закрыты» или закрыты позже выбранной даты,
     должно появиться дерево с подтверждением.
   - при отказе — дата расторжения останется, но запись/дальнейшие действия вы сможете отменить вручную;
     при записи серверная проверка не даст сохранить неконсистентное состояние.
   - при ОК — подчинённые элементы закроются на выбранную дату.

2) Откройте элемент справочника ДепозитарныеСчета, который является разделом (ТипСчета = Раздел депозитарного счета):
   - измените ДатаЗакрытияРаздел → должно появиться дерево с подчиненными элементами (в т.ч. исполнители),
     закрывающимися на указанную дату.

3) Проверка “исполнитель не позже счета” уже есть:
   - РегистрСведений ИсполнителиПоЦеннымБумагам → Модуль набора записей → ПередЗаписью:
     там уже проверяется, что Запись.ДатаЗакрытия <= Запись.ДепозитарныйСчет.ДатаЗакрытия.
