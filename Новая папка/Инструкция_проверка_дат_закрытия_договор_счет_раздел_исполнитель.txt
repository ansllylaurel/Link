ИНСТРУКЦИЯ: проверка/подтверждение дат закрытия договор / счёт / раздел / исполнитель
Дата: 2026-04-20

ВАЖНОЕ ЗАМЕЧАНИЕ ДЛЯ ПОЛЬЗОВАТЕЛЯ
-----------------------------------------------------------------------
Все сообщения (включая добавленные ниже) должны быть ПРЕДУПРЕЖДЕНИЯМИ
без системного “Не удалось записать…”.
Поэтому в добавленных проверках НЕ устанавливаем Отказ и НЕ передаём Отказ
в ОбщегоНазначенияКлиентСервер.СообщитьПользователю().

Общий модуль «РаботаСИсполнителями» не меняется (нет прав / не трогаем).
-----------------------------------------------------------------------

=======================================================================
ИЗМЕНЕНИЕ 1
Объект: РегистрСведений УсловияДоговоровОбщие
Где:    Модуль набора записей (`InformationRegisters\УсловияДоговоровОбщие\Ext\RecordSetModule.bsl`)
Цель:   При записи условий договора выводить предупреждение, если есть
        депозитарные счета с датой закрытия позже даты расторжения (или не закрыты).
        Запись НЕ блокируем.
=======================================================================

ШАГ 1. В процедуре `КонтрольДатыЗакрытияДепозитарныхСчетов(Отказ)` заменить вызов
`СообщитьПользователю(..., Отказ)` на предупреждение без Отказ.

КОД ДО (фрагмент в конце цикла):
------------------------------------------------------------
	Пока Выборка.Следующий() Цикл
		ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
			"Дата закрытия счёта «" + Выборка.Представление + "» позже даты расторжения договора",
			Выборка.Ссылка, , , Отказ);
	КонецЦикла;
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
	Пока Выборка.Следующий() Цикл
		ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
			"Дата закрытия счёта «" + Выборка.Представление + "» позже даты расторжения договора",
			Выборка.Ссылка);
	КонецЦикла;
------------------------------------------------------------

ШАГ 2 (рекомендуется). Аналогично привести к предупреждению проверку по банковским счетам,
если она у вас тоже выдаёт “Не удалось записать…”.

КОД ДО (фрагмент):
------------------------------------------------------------
	Пока Выборка.Следующий() Цикл
		ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
			"Дата закрытия счета «" + Выборка.Представление + "» позже даты расторжения договора",
			Выборка.Ссылка, , , Отказ);
	КонецЦикла;
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
	Пока Выборка.Следующий() Цикл
		ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
			"Дата закрытия счета «" + Выборка.Представление + "» позже даты расторжения договора",
			Выборка.Ссылка);
	КонецЦикла;
------------------------------------------------------------

Примечание:
- Условия вида `Если Отказ Тогда Возврат;` можно оставить (если запись уже отменена
  другими проверками, не “шумим” нашими предупреждениями).
- Главное: в наших добавленных проверках не выставлять `Отказ = Истина`.


=======================================================================
ИЗМЕНЕНИЕ 2
Объект: РегистрСведений УсловияДоговоровОбщие
Где:    Форма записи (клиент/серверный модуль формы)
Цель:   При интерактивном изменении даты расторжения показывать дерево
        закрываемых элементов и, по подтверждению, массово закрывать их.
=======================================================================

Если у вас уже внесена версия “без изменения общего модуля”, то этот блок
трогать не нужно (он не влияет на “Не удалось записать…”).

Критично: если вы где-то показываете сообщения через `СообщитьПользователю(..., Отказ)`
— заменяйте на вариант без Отказ.


=======================================================================
ИЗМЕНЕНИЕ 3
Объект: Справочник ДепозитарныеСчета
Где:    Форма элемента
Цель:   При интерактивном изменении даты закрытия раздела показывать дерево
        исполнителей и, по подтверждению, закрывать их.
=======================================================================

Если у вас уже внесена версия, где дерево строится запросом (без вызова
РаботаСИсполнителями.ПолучитьДочерниеЭлементы), то этот блок трогать не нужно
(он не влияет на “Не удалось записать…”).


=======================================================================
ПРОВЕРКА РЕЗУЛЬТАТА
=======================================================================

1) Условия договора (УсловияДоговоровОбщие):
   Попробуйте записать дату расторжения, когда у договора есть незакрытые
   или закрытые позже счета.
   Ожидаемо: появляется сообщение-предупреждение (без “Не удалось записать…”),
   запись при этом выполняется.

2) Банковские счета (если применимо):
   Аналогично — предупреждение без системной ошибки.
