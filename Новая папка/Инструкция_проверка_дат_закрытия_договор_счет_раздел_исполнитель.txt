ИНСТРУКЦИЯ: проверка дат закрытия договор / счёт / раздел / исполнитель
Дата: 2026-04-17

Общий модуль «РаботаСИсполнителями» не меняется (нет прав / не трогаем).
Для договоров депозитарного обслуживания дерево при расторжении строится
обходом в ширину в модуле формы записи УсловияДоговоровОбщие; для закрытия
раздела — отдельным запросом исполнителей в модуле формы элемента ДепозитарныеСчета.

=======================================================================
ЧТО УЖЕ РАБОТАЕТ (ТРОГАТЬ НЕ НУЖНО)
=======================================================================
- Справочник ДепозитарныеСчета, Модуль объекта, ПередЗаписью:
    * дата закрытия раздела не позднее даты закрытия родительского счёта
    * дата закрытия счёта/раздела не позднее даты расторжения договора
    * вызов РаботаСИсполнителями.ПроверитьДатыЗакрытияДочернихЭлементов
      (проверяет счёт → разделы + исполнители)
- Форма элемента ДепозитарныеСчета, команда КомандаЗакрытьДоговор:
    интерактивное дерево незакрытых элементов + массовое закрытие

=======================================================================
ПРОВЕРКА РЕЗУЛЬТАТА
=======================================================================

1. Запись условий договора (РегистрСведений УсловияДоговоровОбщие):
   Попытайтесь установить дату расторжения договора, если у договора
   есть незакрытые или закрытые позже депозитарные счета.
   Ожидаемый результат: ошибка записи с сообщением
   "Дата закрытия счёта «...» позже даты расторжения договора"

2. Интерактивное расторжение договора:
   Откройте форму записи РегистрСведений УсловияДоговоровОбщие,
   введите дату расторжения для договора, у которого есть
   незакрытые счета/разделы/исполнители.
   Ожидаемый результат: появляется дерево с подчинёнными элементами,
   пользователь подтверждает — они закрываются на указанную дату.

3. Закрытие раздела счёта:
   Откройте форму элемента ДепозитарныеСчета для раздела
   (ТипСчета = РазделДепозитарногоСчета), введите дату закрытия.
   Ожидаемый результат: появляется дерево исполнителей по этому разделу,
   при подтверждении они закрываются на указанную дату.

4. Проверка "раздел не позднее счёта" и "счёт не позднее договора":
   Эти проверки уже существовали, но теперь договор тоже проверяется
   через серверную процедуру при записи.
