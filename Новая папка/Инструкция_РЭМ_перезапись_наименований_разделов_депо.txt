ИНСТРУКЦИЯ: РЭМ — перезаписать существующие наименования разделов депо-счетов
Дата: 2026-04-20

Зачем
-----------------------------------------------------------------------
После изменения шаблона наименования разделов (добавлен номер раздела)
нужно обновить уже существующие элементы, чтобы поле `Наименование`
пересчиталось по новой логике.

Где менять
-----------------------------------------------------------------------
Конфигуратор → Справочники → ДепозитарныеСчета → Модули → Модуль менеджера
Файл выгрузки: `Catalogs\ДепозитарныеСчета\Ext\ManagerModule.bsl`

=======================================================================
ШАГ 1. Добавить процедуру массового обновления наименований (экспорт)
=======================================================================

Вставить ниже функции `СформироватьНаименование(...)` (в этом же модуле):

КОД ДО (ориентир — конец функции):
------------------------------------------------------------
КонецФункции // СформироватьНаименование
------------------------------------------------------------

КОД ПОСЛЕ (вставить сразу после):
------------------------------------------------------------
////////////////////////////////////////////////////////////////////////////////
// СЛУЖЕБНЫЕ МАССОВЫЕ ОПЕРАЦИИ
//
Процедура ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(ТолькоПоказать = Ложь, Максимум = 0) Экспорт
	
	ОрганизацияРЭМ = ОбщегоНазначения.ПолучитьИменованныйОбъект("Организация_РЭМ");
	Если Не ЗначениеЗаполнено(ОрганизацияРЭМ) Тогда
		ОбщегоНазначенияКлиентСервер.СообщитьПользователю("Не найден именованный объект Организация_РЭМ.");
		Возврат;
	КонецЕсли;
	
	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	ДепозитарныеСчета.Ссылка КАК Ссылка
		|ИЗ
		|	Справочник.ДепозитарныеСчета КАК ДепозитарныеСчета
		|ГДЕ
		|	ДепозитарныеСчета.ПометкаУдаления = ЛОЖЬ
		|	И ДепозитарныеСчета.ТипСчета = &ТипСчета
		|	И ДепозитарныеСчета.Организация = &Организация";
	
	Запрос.УстановитьПараметр("ТипСчета",     Перечисления.ТипыДепозитарныхСчетов.РазделДепозитарногоСчета);
	Запрос.УстановитьПараметр("Организация",  ОрганизацияРЭМ);
	
	Просмотрено = 0;
	Изменено    = 0;
	Ошибок      = 0;
	
	Выборка = Запрос.Выполнить().Выбрать();
	Пока Выборка.Следующий() Цикл
		
		Просмотрено = Просмотрено + 1;
		Если Максимум > 0 И Просмотрено > Максимум Тогда
			Прервать;
		КонецЕсли;
		
		Попытка
			Объект = Выборка.Ссылка.ПолучитьОбъект();
			НовоеНаименование = СформироватьНаименование(Объект);
			
			Если ПустаяСтрока(НовоеНаименование) Тогда
				Продолжить;
			КонецЕсли;
			
			Если Объект.Наименование <> НовоеНаименование Тогда
				Изменено = Изменено + 1;
				
				Если Не ТолькоПоказать Тогда
					Объект.Наименование = НовоеНаименование;
					Объект.Записать();
				КонецЕсли;
			КонецЕсли;
			
		Исключение
			Ошибок = Ошибок + 1;
		КонецПопытки;
		
	КонецЦикла;
	
	ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
		"РЭМ: разделы депозитарных счетов. Просмотрено: " + Просмотрено
		+ ", изменено: " + Изменено
		+ ?(ТолькоПоказать, " (без записи)", "")
		+ ", ошибок: " + Ошибок + ".");
	
КонецПроцедуры
------------------------------------------------------------

=======================================================================
ШАГ 2. Как запустить (варианты)
=======================================================================

Вариант А (рекомендуется): через “Консоль кода/запросов” (если доступна)
------------------------------------------------------------
Выполнить:

Справочники.ДепозитарныеСчета.ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(Истина);  // прогон без записи
Справочники.ДепозитарныеСчета.ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(Ложь);    // реальная запись

Для теста на небольшом объёме:
Справочники.ДепозитарныеСчета.ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(Ложь, 100);

Вариант Б: через временную внешнюю обработку (если консоли нет)
------------------------------------------------------------
Создать внешнюю обработку с одной кнопкой “Выполнить” и в модуле команды вызвать:
Справочники.ДепозитарныеСчета.ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(Ложь);
