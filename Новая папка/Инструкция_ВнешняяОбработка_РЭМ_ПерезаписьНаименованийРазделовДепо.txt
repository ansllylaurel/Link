ИНСТРУКЦИЯ: Внешняя обработка (.epf) — РЭМ перезапись наименований разделов депо-счетов
Дата: 2026-04-20

Цель
-----------------------------------------------------------------------
Сделать внешнюю обработку, которую легко запускать на продуктивной базе:
она пересчитает и перезапишет `Наименование` у разделов депозитарных счетов
организации РЭМ по новой логике (включая номер раздела).

ВАЖНО
-----------------------------------------------------------------------
Эта внешняя обработка вызывает экспортную процедуру конфигурации:
`Справочники.ДепозитарныеСчета.ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(...)`.
То есть в продуктивной базе уже должна быть внесена доработка в
`Справочники.ДепозитарныеСчета` (модуль менеджера) с этой процедурой.

Если процедуры нет — внешняя обработка выдаст ошибку "Метод не обнаружен".

=======================================================================
ШАГ 1. Создать внешнюю обработку
=======================================================================
1) Конфигуратор → Файл → Новый → Внешняя обработка.
2) Сохранить как, например:
   `РЭМ_ПерезаписьНаименованийРазделовДепо.epf`
3) Открыть модуль объекта внешней обработки.

=======================================================================
ШАГ 2. Добавить реквизиты и команду формы
=======================================================================
1) Создать основную форму внешней обработки (если не создана).
2) На форме добавить реквизиты:
   - `ТолькоПоказать` (Булево), по умолчанию Истина
   - `Максимум` (Число), по умолчанию 0
3) Добавить команду/кнопку `Выполнить`.

=======================================================================
ШАГ 3. Код модуля формы (рекомендуется)
=======================================================================
Откройте: Внешняя обработка → Формы → (основная форма) → Модуль формы.
Вставьте код.

КОД:
------------------------------------------------------------
&НаКлиенте
Процедура Выполнить(Команда)
	
	Если ТолькоПоказать Тогда
		Если Вопрос(
			"Будет выполнен прогон БЕЗ записи (только подсчёт изменяемых элементов). Продолжить?",
			РежимДиалогаВопрос.ОКОтмена) <> КодВозвратаДиалога.ОК Тогда
			Возврат;
		КонецЕсли;
	Иначе
		Если Вопрос(
			"Будет выполнена ЗАПИСЬ элементов (массовое изменение наименований). Продолжить?",
			РежимДиалогаВопрос.ОКОтмена) <> КодВозвратаДиалога.ОК Тогда
			Возврат;
		КонецЕсли;
	КонецЕсли;
	
	ВыполнитьНаСервере();
	
КонецПроцедуры

&НаСервере
Процедура ВыполнитьНаСервере()
	
	// Основной вызов: вся логика и сообщения внутри процедуры конфигурации
	Справочники.ДепозитарныеСчета.ПерезаписатьНаименованияРазделовДепозитарныхСчетовРЭМ(ТолькоПоказать, Максимум);
	
КонецПроцедуры
------------------------------------------------------------

Примечания:
- `ТолькоПоказать = Истина` — безопасный прогон, без записи.
- `Максимум = 0` — без ограничения; для теста можно поставить 50/100.

=======================================================================
ШАГ 4. Запуск на продуктивной базе
=======================================================================
1) Открыть базу в режиме Предприятие.
2) Файл → Открыть → выбрать `РЭМ_ПерезаписьНаименованийРазделовДепо.epf`.
3) Сначала запустить с `ТолькоПоказать = Истина` (оценить объём).
4) Затем поставить `ТолькоПоказать = Ложь` и выполнить реальную запись.

Ожидаемый результат:
- По завершении выводится сообщение с количеством просмотренных/изменённых/ошибок.
