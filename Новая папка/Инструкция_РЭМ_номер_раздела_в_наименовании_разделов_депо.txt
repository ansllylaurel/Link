ИНСТРУКЦИЯ: РЭМ — добавить номер раздела в наименование разделов депо-счетов
Дата: 2026-04-20

Задача
-----------------------------------------------------------------------
Для организации РЭМ (Именованный объект: "Организация_РЭМ") в наименовании
элементов типа "Раздел депозитарного счета" отображать номер раздела.
Номер раздела берётся из реквизита раздела `НомерСчета`.

Где менять
-----------------------------------------------------------------------
Конфигуратор → Справочники → ДепозитарныеСчета → Модули → Модуль менеджера
Файл выгрузки: `Catalogs\ДепозитарныеСчета\Ext\ManagerModule.bsl`

=======================================================================
ШАГ 1. В функции `СформироватьНаименование` добавить реквизит Организация
в `ЗадействованныеРеквизиты`
=======================================================================

КОД ДО:
------------------------------------------------------------
Функция СформироватьНаименование(РеквизитыСчета, ЗадействованныеРеквизиты = "") Экспорт
	
	ЗадействованныеРеквизиты = "Родитель, Договор, Депозитарий, НомерСчета, ТипСчета, ВидСчета, Попекаемый, Брокер";
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
Функция СформироватьНаименование(РеквизитыСчета, ЗадействованныеРеквизиты = "") Экспорт
	
	ЗадействованныеРеквизиты = "Родитель, Договор, Депозитарий, НомерСчета, ТипСчета, ВидСчета, Попекаемый, Брокер, Организация";
------------------------------------------------------------

=======================================================================
ШАГ 2. Для разделов депозитарного счета: если Организация = РЭМ,
добавить номер раздела (`НомерСчета`) в строку наименования
=======================================================================

НАЙТИ БЛОК:
------------------------------------------------------------
ИначеЕсли РеквизитыСчета.ТипСчета = Перечисления.ТипыДепозитарныхСчетов.РазделДепозитарногоСчета Тогда
	Если ЗначениеЗаполнено(РеквизитыСчета.Родитель) И ЗначениеЗаполнено(РеквизитыСчета.НомерСчета) Тогда
		...
		Наименование = РеквизитыСчета.Родитель.НомерСчета + ", " + ?(Наименование <> "", Наименование + ", ", "") + ?(ЗначениеЗаполнено(РеквизитыСчета.Брокер), РеквизитыСчета.Брокер, "");
	КонецЕсли;
------------------------------------------------------------

КОД ДО (конкретная строка сборки наименования):
------------------------------------------------------------
			Наименование = РеквизитыСчета.Родитель.НомерСчета + ", " + ?(Наименование <> "", Наименование + ", ", "") + ?(ЗначениеЗаполнено(РеквизитыСчета.Брокер), РеквизитыСчета.Брокер, "");
------------------------------------------------------------

КОД ПОСЛЕ:
------------------------------------------------------------
			ОрганизацияРЭМ = ОбщегоНазначения.ПолучитьИменованныйОбъект("Организация_РЭМ");
			ДобавлятьНомерРаздела = ЗначениеЗаполнено(РеквизитыСчета.Организация) И РеквизитыСчета.Организация = ОрганизацияРЭМ;
			
			Наименование = РеквизитыСчета.Родитель.НомерСчета
				+ ?(ДобавлятьНомерРаздела, ", " + РеквизитыСчета.НомерСчета, "")
				+ ", " + ?(Наименование <> "", Наименование + ", ", "")
				+ ?(ЗначениеЗаполнено(РеквизитыСчета.Брокер), РеквизитыСчета.Брокер, "");
------------------------------------------------------------

Результат
-----------------------------------------------------------------------
- Для организации РЭМ: наименование раздела будет содержать номер раздела.
- Для остальных организаций: формат наименования не меняется.

Проверка
-----------------------------------------------------------------------
1) Открыть существующий раздел депозитарного счета с Организация = РЭМ.
2) В форме вызвать пересчёт/установку наименования (если используется автоподстановка)
   или изменить реквизит, который триггерит `УстановитьНовоеНаименование`.
3) Убедиться, что в `Наименование` появился номер раздела (значение `НомерСчета` раздела).
