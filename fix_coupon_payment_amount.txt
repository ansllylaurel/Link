ИНСТРУКЦИЯ ПО РУЧНОМУ ПРИМЕНЕНИЮ ИЗМЕНЕНИЙ
Исправление суммы оплаты купона (ПогашениеКупона -> Оплата)
================================================================================

ФАЙЛ ДЛЯ РЕДАКТИРОВАНИЯ
------------------------
Documents\ПогашениеКупона\Ext\ObjectModule.bsl

В конфигураторе 1С:
  Документы -> ПогашениеКупона -> Модуль объекта

Процедура: ПроведениеПоРегистрамБэкОфиса
Блок: "// задолженность по д/с" (движения по регистру ЗадолженностиПоДенежнымСредствам)


================================================================================
ИЗМЕНЕНИЕ 1 из 5  (основной приход по эмитенту)
================================================================================

Найдите строки:

    Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
    Движение.СуммаКупона                  = ЭтотОбъект.Количество * ЭтотОбъект.СуммаНаОднуОблигацию;

    СуммаВРЕПО = 0;

Замените на:

    Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
    Движение.СуммаКупона                  = ЭтотОбъект.Количество * ЭтотОбъект.СуммаНаОднуОблигациюВВалютеОплаты;

    СуммаВРЕПО = 0;


================================================================================
ИЗМЕНЕНИЕ 2 из 5  (расход по РЕПО — уменьшение задолженности эмитента)
================================================================================

Найдите строки (внутри блока "Если ОстаткиЦенныхБумаг.Итог("КоличествоВРЕПО") > 0 Тогда"):

        Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
        Движение.СуммаКупона                  = ОстаткиЦенныхБумаг.Итог("КоличествоВРЕПО") * ЭтотОбъект.СуммаНаОднуОблигацию;

        СуммаВРЕПО = Движение.СуммаКупона;

Замените на:

        Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
        Движение.СуммаКупона                  = ОстаткиЦенныхБумаг.Итог("КоличествоВРЕПО") * ЭтотОбъект.СуммаНаОднуОблигациюВВалютеОплаты;

        СуммаВРЕПО = Движение.СуммаКупона;


================================================================================
ИЗМЕНЕНИЕ 3 из 5  (приход контрагентам по возврату купонного дохода — РЕПО)
================================================================================

Найдите строки (внутри цикла "Для Каждого СтрокаОстатков Из ОстаткиЦенныхБумаг Цикл"):

            Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
            Движение.СуммаКупона                  = СтрокаОстатков.КоличествоВРЕПО * ЭтотОбъект.СуммаНаОднуОблигацию;

            СуммаВРЕПО = СуммаВРЕПО - Движение.СуммаКупона;

Замените на:

            Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
            Движение.СуммаКупона                  = СтрокаОстатков.КоличествоВРЕПО * ЭтотОбъект.СуммаНаОднуОблигациюВВалютеОплаты;

            СуммаВРЕПО = СуммаВРЕПО - Движение.СуммаКупона;


================================================================================
ИЗМЕНЕНИЕ 4 из 5  (инициализация суммы по РЕПО-контрагенту)
================================================================================

Найдите строку (в начале цикла "Для Каждого СтрокаРепоПоКонтрагентам Из РепоПоКонтрагентам Цикл"):

        СуммаПоРепоПоКонтрагенту = СтрокаРепоПоКонтрагентам.КоличествоПоРЕПО * ЭтотОбъект.СуммаНаОднуОблигацию;

Замените на:

        СуммаПоРепоПоКонтрагенту = СтрокаРепоПоКонтрагентам.КоличествоПоРЕПО * ЭтотОбъект.СуммаНаОднуОблигациюВВалютеОплаты;


================================================================================
ИЗМЕНЕНИЕ 5 из 5  (приход по позициям РЕПО контрагентов)
================================================================================

Найдите строки (во вложенном цикле "Для Каждого СтрокаОстатков Из НайденныеСтроки Цикл"):

                Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
                Движение.СуммаКупона                  = СтрокаОстатков.КоличествоПоРЕПО * ЭтотОбъект.СуммаНаОднуОблигацию;

                СуммаПоРепоПоКонтрагенту = СуммаПоРепоПоКонтрагенту - Движение.СуммаКупона;

Замените на:

                Движение.Валюта                       = ЭтотОбъект.ВалютаОплаты;
                Движение.СуммаКупона                  = СтрокаОстатков.КоличествоПоРЕПО * ЭтотОбъект.СуммаНаОднуОблигациюВВалютеОплаты;

                СуммаПоРепоПоКонтрагенту = СуммаПоРепоПоКонтрагенту - Движение.СуммаКупона;


================================================================================
СТРОКИ, КОТОРЫЕ МЕНЯТЬ НЕ НУЖНО
================================================================================

В той же процедуре ниже есть строка:

    Движение.СуммаКупона = ЭтотОбъект.Количество * ЭтотОбъект.СуммаНаОднуОблигацию;

для регистра ОперацииСЦеннымиБумагами — эту строку НЕ трогать.
Она расположена ПОСЛЕ комментария "// операции с ц/б".


================================================================================
СУТЬ ИСПРАВЛЕНИЯ
================================================================================

Было: в регистр ЗадолженностиПоДенежнымСредствам записывалась сумма купона
      в валюте номинала (СуммаНаОднуОблигацию), хотя поле Валюта = ВалютаОплаты.

Стало: записывается сумма в валюте оплаты (СуммаНаОднуОблигациюВВалютеОплаты),
       что соответствует значению поля Валюта.

Результат: при создании документа Оплата на основании ПогашениеКупона сумма
           оплаты купона (СуммаОплатыКупона) теперь совпадает с плановой
           суммой из НСИ-регистра КупонныйДоходПоОблигациям.

Для рублёвых облигаций (ВалютаНоминала = ВалютаОплаты) изменение не влияет,
так как СуммаНаОднуОблигацию = СуммаНаОднуОблигациюВВалютеОплаты.
