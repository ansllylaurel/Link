Назначение обработки

Проверка просроченной задолженности по оплатам по погашению купона и погашению облигаций. Рассылка сведений о задолженности.

Структура запроса

Данные о задолжености берутся из регистра сведений Задолженности по денежным средствам. Отдельно рассматривается задолженность по купону (По погашению купона, по последнему погашению купона) и отдельно по погашению облигации (По погашению облигации, по последнему погашению облигации). Сведения по ценной бумаге берутся из документа-регистратора. Для случая, когда задолженость создана документом Ввод ценных бумаг, нельзя однозначно установить облигацию, к которой относится задолженость. В этом случае из документа берутся те строки, по которым соответсвующие суммы дебеторской задолженности больше нуля.

Дефолтные ценные бумаги отбрасываются.

Данные о плановых и фактических датах оплаты берутся из регистров сведений Купонные доходы по облигация и Номиналы ценных бумаг. В свою очередь эти сведения берутся из MatriX_External и закачиваются обработкой Импорт нормативно-сравочной информации. Такие сведения есть не у всех бумаг, точнее есть редко у какой бумаги. В регистре Номиналы ценных бумаг нет записей относящихся к последнему погашению облигации, также нельзя получить плановую и фактическую дату оплаты для погашения неамортизируемых облигаций.

В случае если даты оплаты неизвестны, мы получаем их прибавив к дате возникновения задолженности (дате документа) 4 дня.
