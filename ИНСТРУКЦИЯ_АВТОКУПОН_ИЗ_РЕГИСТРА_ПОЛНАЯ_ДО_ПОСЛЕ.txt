ИНСТРУКЦИЯ ДЛЯ РУЧНОЙ ПРАВКИ КОНФИГУРАЦИИ 1С (КОД ДО / КОД ПОСЛЕ)
Тема: Автоподстановка купона из регистра (валюта + RUB), регистр — эталон
================================================================================
Дата: 2026-03-26

ТРЕБОВАНИЕ
----------
1) Сумма купона на одну облигацию (в валюте) и сумма купона на одну облигацию в RUB
   должны ВСЕГДА браться из регистра сведений "КупонныйДоходПоОблигациям":
   - измерение: Облигация
   - ресурс: СуммаКупона
   - ресурс: СуммаКупонаВРублях
   - отбор по дате: ДатаОкончанияКупона = Дата (на форме обработки)

2) Ручной ввод этих сумм пользователем запрещен (поля только просмотр).

3) Если уже есть созданные документы "ПогашениеКупона", они НЕ являются источником
   суммы на одну облигацию для формы обработки. Эталон — регистр.

  DataProcessors\СводноеПогашениеКупона\Forms\Основная\Ext\Form\Module.bsl

ИЗМЕНЕНИЕ 2. ЗаполнитьПлановыеИСозданныеПогашенияНаСервере — всегда обновлять суммы из регистра
================================================================================

КАК НАЙТИ:
  Ctrl+F → "Функция ЗаполнитьПлановыеИСозданныеПогашенияНаСервере"
  Затем внутри найти блок:
    "Если ЭтаФорма.СуммаНаОднуОблигацию = 0"

КОД ДО (подстановка была только валютной суммы и только если поле = 0):

Если ЭтаФорма.СуммаНаОднуОблигацию = 0 И Не Элементы.СуммаНаОднуОблигацию.ТолькоПросмотр Тогда
	СуммаПоГрафику = ПолучитьСуммуКупонаИзГрафика(ЭтаФорма.Облигация, ЭтаФорма.Дата);
	Если СуммаПоГрафику > 0 Тогда
		ЭтаФорма.СуммаНаОднуОблигацию = СуммаПоГрафику;
	КонецЕсли;
КонецЕсли;

КОД ПОСЛЕ (всегда берём из регистра, обе суммы, ручной ввод отключаем):

ОбновитьСуммыНаОднуОблигациюИзРегистра();

ВАЖНО:
Этот вызов должен стоять ДО заполнения таблиц, чтобы все расчеты сумм в таблицах
шли от значений, взятых из регистра.

КОД ДО:

&НаСервереБезКонтекста
Функция ПолучитьСуммуКупонаИзГрафика(Облигация, Дата)
	
	Если Не ЗначениеЗаполнено(Облигация) Или Не ЗначениеЗаполнено(Дата) Тогда
		Возврат 0;
	КонецЕсли;
	
	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	КупонныйДоходПоОблигациям.СуммаКупона КАК СуммаКупона
		|ИЗ
		|	РегистрСведений.КупонныйДоходПоОблигациям КАК КупонныйДоходПоОблигациям
		|ГДЕ
		|	КупонныйДоходПоОблигациям.Облигация = &Облигация
		|	И КупонныйДоходПоОблигациям.ДатаОкончанияКупона = &Дата";

	Запрос.УстановитьПараметр("Дата",      Дата);

	Если Выборка.Следующий() Тогда
		Возврат Выборка.СуммаКупона;
	КонецЕсли;
	
	Возврат 0;
	
КонецФункции // ПолучитьСуммуКупонаИзГрафика

КОД ПОСЛЕ (новая функция возвращает структуру с двумя суммами):

&НаСервереБезКонтекста
Функция ПолучитьСуммыКупонаИзРегистра(Облигация, Дата)
	
	Результат = Новый Структура("СуммаКупона,СуммаКупонаВРублях", 0, 0);
	
	Если Не ЗначениеЗаполнено(Облигация) Или Не ЗначениеЗаполнено(Дата) Тогда
		Возврат Результат;
	КонецЕсли;
	
	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	КупонныйДоходПоОблигациям.СуммаКупона КАК СуммаКупона,
		|	КупонныйДоходПоОблигациям.СуммаКупонаВРублях КАК СуммаКупонаВРублях
		|ИЗ
		|	РегистрСведений.КупонныйДоходПоОблигациям КАК КупонныйДоходПоОблигациям
		|ГДЕ
		|	КупонныйДоходПоОблигациям.Облигация = &Облигация
		|	И КупонныйДоходПоОблигациям.ДатаОкончанияКупона = &Дата";
	
	Запрос.УстановитьПараметр("Облигация", Облигация);
	Запрос.УстановитьПараметр("Дата",      Дата);
	
	Выборка = Запрос.Выполнить().Выбрать();
	Если Выборка.Следующий() Тогда
		Результат.СуммаКупона = Выборка.СуммаКупона;
		Результат.СуммаКупонаВРублях = Выборка.СуммаКупонаВРублях;
	КонецЕсли;
	
	Возврат Результат;
	
КонецФункции // ПолучитьСуммыКупонаИзРегистра

================================================================================

&НаСервере
Процедура ОбновитьСуммыНаОднуОблигациюИзРегистра()
	
	// Регистр "КупонныйДоходПоОблигациям" — эталон. Ручной ввод отключаем.
	Элементы.СуммаНаОднуОблигацию.ТолькоПросмотр = Истина;
	Элементы.СуммаНаОднуОблигациюВРублях.ТолькоПросмотр = Истина;
	
	Если Не ЗначениеЗаполнено(ЭтаФорма.Облигация) Или Не ЗначениеЗаполнено(ЭтаФорма.Дата) Тогда
		ЭтаФорма.СуммаНаОднуОблигацию = 0;
		ЭтаФорма.СуммаНаОднуОблигациюВРублях = 0;
		Возврат;
	КонецЕсли;
	
	СуммыИзРегистра = ПолучитьСуммыКупонаИзРегистра(ЭтаФорма.Облигация, ЭтаФорма.Дата);
	
	ЭтаФорма.СуммаНаОднуОблигацию = СуммыИзРегистра.СуммаКупона;
	ЭтаФорма.СуммаНаОднуОблигациюВРублях = СуммыИзРегистра.СуммаКупонаВРублях;
	
	Если ЭтаФорма.СуммаНаОднуОблигацию = 0 И ЭтаФорма.СуммаНаОднуОблигациюВРублях = 0 Тогда
		ОбщегоНазначенияКлиентСервер.СообщитьПользователю(
			"В регистре ""Купонный доход по облигациям"" не найдены суммы купона (в валюте и в рублях) для облигации " 
			+ Строка(ЭтаФорма.Облигация) + " на дату " + Формат(ЭтаФорма.Дата, "ДФ=dd.MM.yyyy") + ".");
	КонецЕсли;
	
КонецПроцедуры

ПОСЛЕ ПРАВОК — КАК ПРИМЕНИТЬ
================================================================================
1) Сохранить (Ctrl+S) в конфигураторе.
2) Обновить конфигурацию БД (F7).
3) Проверка:
   - В регистре "Купонный доход по облигациям" есть запись на выбранную облигацию и дату окончания купона.
   - Открыть обработку → выбрать облигацию/дату → суммы на одну облигацию (валюта и RUB) подставились и недоступны.
   - Таблицы плановых/созданных: суммы считаются от этих значений.
