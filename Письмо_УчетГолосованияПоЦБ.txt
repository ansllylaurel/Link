Тема: Реализован учёт осуществления права голоса по ценным бумагам (482-П, п. 4.4.6)

Коллеги, добрый день.

В конфигурации 1С реализован учёт осуществления права голоса по ценным бумагам и вывод этих данных в отчёт управляющего 482-П.

Что сделано:

1. Документ «Осуществление права голоса по ценным бумагам» — один документ на одну ценную бумагу и одно собрание, сразу по всем нужным клиентам (счетам ДУ). Можно заводить несколько документов (разные ЦБ, собрания, даты голосования).

2. Автозаполнение клиентов — по остаткам выбранной ЦБ на дату голосования, с возможностью ручной корректировки списка и массового удаления по виду договора (например, все ИИС).

3. Учёт вариантов голосования — по каждому вопросу повестки дня: За / Против / Воздержался (общие для всех выбранных клиентов в документе).

4. Контроль дублей — при проведении предупреждение, если по тому же портфелю, ЦБ и собранию уже есть документ голосования.

5. Прикрепление файлов — к документу можно приложить скан бюллетеня или иного подтверждения (скрепка).

6. Отчёт 482-П, п. 4.4.6 — при наличии данных за отчётный период в отчёт автоматически выводится таблица голосований (ЦБ, собрание, вопрос, вариант голосования) по каждому счёту ДУ.

Где найти: Бэк-офис УК → Ценные бумаги → Осуществление права голоса по ценным бумагам.

Во вложении — скриншот заполненной формы документа с примером типового сценария заполнения.

Прошу ознакомиться. Если будут замечания или пожелания по доработке — сообщите.
