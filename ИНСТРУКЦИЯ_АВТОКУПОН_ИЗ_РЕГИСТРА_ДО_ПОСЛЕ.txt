ИНСТРУКЦИЯ ДЛЯ РУЧНОЙ ПРАВКИ КОНФИГУРАЦИИ 1С
Тема: автоподстановка купона (валюта + RUB) из регистра "КупонныйДоходПоОблигациям"
================================================================================
Дата: 2026-03-26

Цель
-----
В обработке "СводноеПогашениеКупона" суммы:
- "Сумма на одну облигацию" (в валюте номинала)
- "Сумма на одну облигацию в рублях"
должны при открытии формы подставляться из регистра сведений "КупонныйДоходПоОблигациям"
(ресурсы: СуммаКупона, СуммаКупонаВРублях) для выбранной облигации и даты окончания купона.

ВАЖНО
-----
Ниже приведены блоки "КОД ДО / КОД ПОСЛЕ" для внесения вручную в конфигуратор.
Правки делаются в модуле формы:
  Обработки → СводноеПогашениеКупона → Формы → Основная → Модуль

DataProcessors/СводноеПогашениеКупона/Forms/Основная/Ext/Form/Module.bsl

ИЗМЕНЕНИЕ 1. Функция получения купона из регистра: ДО / ПОСЛЕ
--------------------------------------------------------------------------------

КАК НАЙТИ:
  В модуле формы нажать Ctrl+F и найти:
    "Функция ПолучитьСуммуКупонаИзГрафика"

КОД ДО (как сейчас):

Функция ПолучитьСуммуКупонаИзГрафика(Облигация, Дата)
	
	Если Не ЗначениеЗаполнено(Облигация) Или Не ЗначениеЗаполнено(Дата) Тогда
		Возврат 0;
	КонецЕсли;
	
	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	КупонныйДоходПоОблигациям.СуммаКупона КАК СуммаКупона
		|ИЗ
		|	РегистрСведений.КупонныйДоходПоОблигациям КАК КупонныйДоходПоОблигациям
		|ГДЕ
		|	КупонныйДоходПоОблигациям.Облигация = &Облигация
		|	И КупонныйДоходПоОблигациям.ДатаОкончанияКупона = &Дата";
	
	Запрос.УстановитьПараметр("Облигация", Облигация);
	Запрос.УстановитьПараметр("Дата",      Дата);
	
	Выборка = Запрос.Выполнить().Выбрать();
	Если Выборка.Следующий() Тогда
		Возврат Выборка.СуммаКупона;
	КонецЕсли;
	
	Возврат 0;
	
КонецФункции // ПолучитьСуммуКупонаИзГрафика


КОД ПОСЛЕ (заменить полностью на этот вариант):
Примечание: функция возвращает Структуру с двумя суммами.

&НаСервереБезКонтекста
Функция ПолучитьСуммыКупонаИзГрафика(Облигация, Дата)
	
	Результат = Новый Структура("СуммаКупона,СуммаКупонаВРублях", 0, 0);
	
	Если Не ЗначениеЗаполнено(Облигация) Или Не ЗначениеЗаполнено(Дата) Тогда
		Возврат Результат;
	КонецЕсли;
	
	Запрос = Новый Запрос;
	Запрос.Текст =
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	КупонныйДоходПоОблигациям.СуммаКупона КАК СуммаКупона,
		|	КупонныйДоходПоОблигациям.СуммаКупонаВРублях КАК СуммаКупонаВРублях
		|ИЗ
		|	РегистрСведений.КупонныйДоходПоОблигациям КАК КупонныйДоходПоОблигациям
		|ГДЕ
		|	КупонныйДоходПоОблигациям.Облигация = &Облигация
		|	И КупонныйДоходПоОблигациям.ДатаОкончанияКупона = &Дата";
	
	Запрос.УстановитьПараметр("Облигация", Облигация);
	Запрос.УстановитьПараметр("Дата",      Дата);
	
	Выборка = Запрос.Выполнить().Выбрать();
	Если Выборка.Следующий() Тогда
		Результат.СуммаКупона = Выборка.СуммаКупона;
		Результат.СуммаКупонаВРублях = Выборка.СуммаКупонаВРублях;
	КонецЕсли;
	
	Возврат Результат;
	
КонецФункции // ПолучитьСуммыКупонаИзГрафика


--------------------------------------------------------------------------------
ИЗМЕНЕНИЕ 2. Подстановка при открытии/обновлении формы: ДО / ПОСЛЕ
--------------------------------------------------------------------------------

ГДЕ НАХОДИТСЯ:
  В той же форме "Основная", в функции:
    "ЗаполнитьПлановыеИСозданныеПогашенияНаСервере"

КАК НАЙТИ:
  Ctrl+F → найти фрагмент:
    "Если ЭтаФорма.СуммаНаОднуОблигацию = 0"

КОД ДО (как сейчас, подставляет ТОЛЬКО валютную сумму):

Если ЭтаФорма.СуммаНаОднуОблигацию = 0 И Не Элементы.СуммаНаОднуОблигацию.ТолькоПросмотр Тогда
	СуммаПоГрафику = ПолучитьСуммуКупонаИзГрафика(ЭтаФорма.Облигация, ЭтаФорма.Дата);
	Если СуммаПоГрафику > 0 Тогда
		ЭтаФорма.СуммаНаОднуОблигацию = СуммаПоГрафику;
	КонецЕсли;
КонецЕсли;


КОД ПОСЛЕ (заменить этот блок на блок ниже):
Вариант: подставлять из регистра, только если оба значения ещё не заполнены (0).

Если (ЭтаФорма.СуммаНаОднуОблигацию = 0 И ЭтаФорма.СуммаНаОднуОблигациюВРублях = 0)
	И Не Элементы.СуммаНаОднуОблигацию.ТолькоПросмотр Тогда
	
	СуммыПоГрафику = ПолучитьСуммыКупонаИзГрафика(ЭтаФорма.Облигация, ЭтаФорма.Дата);
	
	Если СуммыПоГрафику.СуммаКупона > 0 Тогда
		ЭтаФорма.СуммаНаОднуОблигацию = СуммыПоГрафику.СуммаКупона;
	КонецЕсли;
	
	Если СуммыПоГрафику.СуммаКупонаВРублях > 0 Тогда
		ЭтаФорма.СуммаНаОднуОблигациюВРублях = СуммыПоГрафику.СуммаКупонаВРублях;
	КонецЕсли;
	
КонецЕсли;


--------------------------------------------------------------------------------
КОНТРОЛЬ/ПРОВЕРКА ПОСЛЕ ВНЕСЕНИЯ
--------------------------------------------------------------------------------
1) Сохранить конфигурацию
2) Обновить конфигурацию БД (F7)
3) Запустить предприятие
4) Открыть обработку "СводноеПогашениеКупона"
5) Выбрать облигацию и дату окончания купона, для которых в регистре есть запись
6) Убедиться:
   - Поле "Сумма на одну облигацию" заполнено из регистра
   - Поле "Сумма на одну облигацию в рублях" заполнено из регистра
   - Дальше суммы по строкам (в т.ч. RUB) считаются от этих значений

--------------------------------------------------------------------------------
ЧАСТЫЕ ПРОБЛЕМЫ
--------------------------------------------------------------------------------
1) Ошибка "Процедура или функция не определена (ПолучитьСуммыКупонаИзГрафика)":
   - значит, блок замены в "ЗаполнитьПлановые..." сделали, а новую функцию не добавили/не сохранили

2) Ошибка "Поле объекта не обнаружено (СуммаКупонаВРублях)":
   - проверьте, что ресурс в регистре реально называется "СуммаКупонаВРублях"
     (в вашем проекте он есть в InformationRegisters/КупонныйДоходПоОблигациям.xml)

3) В регистре нет записи на дату:
   - подстановка вернёт 0, и поля останутся нулевыми (это ожидаемо для выбранного варианта)
