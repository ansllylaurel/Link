Пояснение кода обработки простыми словами
Обработка: _РегистрацияФинансовыхПоказателейПоИИС
Файлы:
1) _РегистрацияФинансовыхПоказателейПоИИС\Ext\ObjectModule.bsl
2) _РегистрацияФинансовыхПоказателейПоИИС\Forms\Форма\Ext\Form\Module.bsl

=====================================================================
1. Общая идея обработки
=====================================================================
Обработка делает две главные задачи:
1) Сверяет и (при необходимости) регистрирует финансовые показатели в документах 1С.
2) Формирует XML по стратегиям для сайта, сохраняет файлы в папку, сверяет их с прошлым периодом,
   отправляет уведомления и делает попытку размещения на сайте.

=====================================================================
2. ObjectModule.bsl — объяснение каждой процедуры/функции
=====================================================================

---------------------------------------------------------------------
Функция СведенияОВнешнейОбработке()
---------------------------------------------------------------------
Что делает:
- Регистрирует обработку в механизме дополнительных обработок.
- Объявляет команды, которые можно запускать:
  - ОтправитьОтчет
  - РегистрацияФинансовыхПоказателей
  - РазместитьДоходностьНаСайте

Зачем нужна:
- Без нее 1С не понимает, как показывать и запускать эту внешнюю обработку.

---------------------------------------------------------------------
Процедура ВыполнитьКоманду(ИдентификаторКоманды, ПараметрыОбработки)
---------------------------------------------------------------------
Что делает:
- Точка входа для запуска по команде/регламенту.
- Заполняет период (конец прошлого месяца) и организацию.
- Маршрутизирует выполнение:
  - "ОтправитьОтчет" -> формирование и отправка отчета.
  - "РазместитьДоходностьНаСайте" -> полный поток размещения.
  - иначе -> проверка 5-го рабочего дня и запуск расчета/регистрации показателей.

Зачем нужна:
- Это диспетчер, который решает, какой сценарий выполнять.

---------------------------------------------------------------------
Процедура ОтправитьОтчет(ПолучателиОповещения)
---------------------------------------------------------------------
Что делает:
- Формирует HTML-отчет по стратегиям и показателям.
- Создает XML-вложения по стратегиям.
- Отправляет письмо с HTML-телом и XML-вложениями.

Внутренние блоки:
1) #Область ПечатнаяФормаШапка
   - берет макет табличного документа и готовит области для вывода строк.
2) #Область Запрос
   - получает пакет данных через ПолучитьПакетДляДоходности().
3) #Область ПечатнаяФормаСтроки
   - выводит по каждой стратегии строку с показателями или ошибку "не зарегистрированы".
4) #Область Вложения
   - вызывает СформироватьXMLВложенияПоСтратегиям().

---------------------------------------------------------------------
Функция ПолучитьПакетДляДоходности()
---------------------------------------------------------------------
Что делает:
- Формирует и выполняет пакетный запрос.
- Возвращает 2 набора:
  1) данные на текущую дату (по стратегиям и показателям),
  2) исторические данные по периодам (для XML выгрузки).

Зачем нужна:
- Центральная функция данных; один источник правды для отчета и размещения.

---------------------------------------------------------------------
Функция СформироватьXMLВложенияПоСтратегиям(Пакет)
---------------------------------------------------------------------
Что делает:
- На основе второго результата пакета строит XML по каждой стратегии:
  - корневой узел ДоходностьПоСтратегии
  - по каждому периоду узел ПоказателиЗаПериод с атрибутами
- Возвращает Соответствие "ИмяФайла -> ДвоичныеДанные".

Зачем нужна:
- Унифицирует генерацию XML, чтобы не дублировать код.

---------------------------------------------------------------------
Процедура ВыполнитьРазмещениеДоходностиНаСайте(ПолучателиОповещения)
---------------------------------------------------------------------
Что делает:
- Оркестратор полного сценария:
  1) получить пакет,
  2) сформировать XML,
  3) сохранить XML в сетевую папку,
  4) проверить расхождения с прошлым файлом,
  5) отправить письмо о расхождениях,
  6) попытаться разместить файлы на сайте,
  7) отправить итоговый отчет.
- Обернуто в Попытка/Исключение с записью ошибки в журнал.

Зачем нужна:
- Это главный бизнес-сценарий из ТЗ "размещение доходности на сайте".

---------------------------------------------------------------------
Функция ПолучитьБазовыйКаталогДоходности()
---------------------------------------------------------------------
Что делает:
- Возвращает базовый UNC-путь для хранения XML.

Зачем нужна:
- Концентрация пути в одном месте.

---------------------------------------------------------------------
Функция ПолучитьКаталогПериода(Период)
---------------------------------------------------------------------
Что делает:
- Добавляет к базовому пути подпапку периода вида yyyy-MM.

Зачем нужна:
- Чтобы файлы лежали по месяцам.

---------------------------------------------------------------------
Функция СохранитьXMLФайлыВСеть(Вложения, КаталогНазначения)
---------------------------------------------------------------------
Что делает:
- Проверяет/создает папку.
- Сохраняет каждый XML-файл на диск.
- Формирует таблицу результата по каждому файлу:
  ИмяФайла, ПолныйПуть, Успешно, ТекстОшибки.

Зачем нужна:
- Первый технический шаг ТЗ: стабильно записывать файлы в сетевую папку.

---------------------------------------------------------------------
Функция ПроверитьРасхожденияПоСохраненнымФайлам(РезультатСохранения, Период)
---------------------------------------------------------------------
Что делает:
- Для каждого сохраненного файла ищет файл прошлого месяца той же стратегии.
- Если файл найден, сравнивает данные.
- Возвращает таблицу: ИмяФайла, ЕстьРасхождения, ОписаниеРасхождений.

Зачем нужна:
- Реализует правило ТЗ про сверку перед размещением.

---------------------------------------------------------------------
Функция ПолучитьПутьПредыдущегоФайлаСтратегии(ИмяФайла, Период)
---------------------------------------------------------------------
Что делает:
- Заменяет в имени суффикс текущего периода на предыдущий.
- Строит путь в папке прошлого месяца.
- Возвращает путь, если файл существует, иначе пустую строку.

---------------------------------------------------------------------
Функция СравнитьXMLФайлыПоПериодам(ПутьТекущегоФайла, ПутьПредыдущегоФайла)
---------------------------------------------------------------------
Что делает:
- Считывает данные периодов из двух XML.
- Сравнивает строки по каждому периоду из прошлого файла.
- Возвращает массив текстовых расхождений.

Примечание:
- Сравнение строковое (по строкам XML), не XSD-уровень.

---------------------------------------------------------------------
Функция ПолучитьДанныеПериодовИзXML(ПутьФайла)
---------------------------------------------------------------------
Что делает:
- Читает XML как текст.
- Ищет строки с тегом ПоказателиЗаПериод.
- Кладет в Соответствие:
  ключ = значение атрибута Период,
  значение = вся строка тега.

---------------------------------------------------------------------
Функция ИзвлечьЗначениеАтрибутаИзСтрокиXML(СтрокаXML, ИмяАтрибута)
---------------------------------------------------------------------
Что делает:
- Достает из строки значение атрибута по имени.
- Возвращает пустую строку, если атрибут не найден.

---------------------------------------------------------------------
Процедура ОтправитьОповещениеОРасхождениях(ПолучателиОповещения, РезультатСверки)
---------------------------------------------------------------------
Что делает:
- Собирает текст по всем файлам, где есть расхождения.
- Если расхождений нет, ничего не отправляет.
- Если есть, отправляет текстовое письмо.

---------------------------------------------------------------------
Функция РазместитьФайлыНаСайте(РезультатСохранения, РезультатСверки)
---------------------------------------------------------------------
Что делает:
- Для каждого файла проверяет:
  1) файл успешно сохранен,
  2) нет расхождений.
- Только после этого делает HTTP GET в сторону сайта.
- Заполняет таблицу результата:
  ИмяФайла, Успешно, Ссылка, ТекстОшибки.

Важно:
- Сейчас используются настройки из ДополнительныеСвойства:
  АдресСайта, СкриптРазмещения, ПрефиксПубличнойСсылки.
- Если они пустые, размещение пропускается с пояснением в ошибке.

---------------------------------------------------------------------
Функция ПолучитьНастройкиРазмещенияНаСайте()
---------------------------------------------------------------------
Что делает:
- Читает настройки размещения из ДополнительныеСвойства.
- Возвращает структуру с 3 полями:
  АдресСайта, СкриптРазмещения, ПрефиксПубличнойСсылки.

---------------------------------------------------------------------
Процедура ОтправитьИтоговыйОтчетОРазмещении(ПолучателиОповещения, РезультатРазмещения)
---------------------------------------------------------------------
Что делает:
- Собирает итоговое письмо:
  - по каждому файлу либо ссылка, либо предупреждение о неразмещении.
- Отправляет письмо списку получателей.

---------------------------------------------------------------------
Функция ПолучитьПоказателиСтандартнойСтратегииДляВыгрузкиНаСайт()
---------------------------------------------------------------------
Что делает:
- Возвращает массив нужных видов показателей:
  СтоимостьПортфеля, Доход, Доходность, СреднемесячнаяДоходность.

Зачем нужна:
- Используется как фильтр показателей в запросах.

---------------------------------------------------------------------
Функция РассчитатьИЗарегистрироватьФинансовыеПоказатели()
---------------------------------------------------------------------
Что делает:
- Загружает список стратегий/документов на период.
- Считает расчетные показатели.
- Берет текущие записанные показатели (из документов).
- Сравнивает текущие и расчетные.
- Если есть отличие хотя бы по одному показателю:
  - ставит ЕстьРасхождения,
  - вызывает ЗарегистрироватьФинансовыеПоказатели(...),
  - возвращает Истина (данные обновлены).
- Если отличий нет или стратегий нет:
  - возвращает Ложь.

Ключевая причина сообщения "Обновление показателей не требуется":
- функция вернула Ложь.

---------------------------------------------------------------------
Процедура ЗарегистрироватьФинансовыеПоказатели(СтрокаФинансовыеПоказатели, Ответственный)
---------------------------------------------------------------------
Что делает:
- Создает новый документ РегистрацияФинансовыхПоказателей или открывает существующий.
- Очищает табличную часть (если документ уже был).
- Записывает расчетные значения показателей (1..10).
- Проводит документ.
- Проставляет ссылку на документ в строке таблицы обработки.

=====================================================================
4. Почему часто появляется "Обновление показателей не требуется"
=====================================================================
Сообщение появляется, когда функция РассчитатьИЗарегистрироватьФинансовыеПоказатели() вернула Ложь.
Основные причины:
1) Нет стратегий, попадающих в отбор запроса (организация/период/стандартные/активность).
2) Для отобранных стратегий расчетные и текущие значения совпадают полностью.
3) Нет исходных данных для расчета, из-за чего новых отличий не возникает.

=====================================================================
5. Как протестировать корректно (практика)
=====================================================================
Минимальный сценарий:
1) Выберите организацию и период, где точно есть стандартные стратегии.
2) Убедитесь, что по ним есть исходные финансовые данные за период.
3) Сделайте тестовое отличие:
   - откройте один документ РегистрацияФинансовыхПоказателей за период,
   - измените значение показателя вручную (например на +1),
   - запустите обработку снова.
4) Ожидаемо:
   - появится "Показатели зарегистрированы",
   - документ будет перезаписан расчетными значениями.

Альтернативный сценарий:
- Для одной стратегии удалите документ регистрации за период и запустите расчет.
- Если расчетные данные есть, обработка должна создать новый документ и вернуть обновление.

Проверка нового сценария размещения:
1) Заполнить в ДополнительныеСвойства:
   - АдресСайта
   - СкриптРазмещения
   - ПрефиксПубличнойСсылки
2) Запустить команду РазместитьДоходностьНаСайте.
3) Проверить:
   - файлы в сетевой папке yyyy-MM,
   - письмо о расхождениях (если есть),
   - итоговое письмо со ссылками/ошибками.
