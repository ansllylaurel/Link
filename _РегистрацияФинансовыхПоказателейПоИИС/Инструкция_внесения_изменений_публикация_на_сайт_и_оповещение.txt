ИНСТРУКЦИЯ ПО ВНЕСЕНИЮ ИЗМЕНЕНИЙ В КОД
Обработка: _РегистрацияФинансовыхПоказателейПоИИС
Файл модуля: Link\_РегистрацияФинансовыхПоказателейПоИИС\_РегистрацияФинансовыхПоказателейПоИИС\Ext\ObjectModule.bsl

ЦЕЛЬ
1) Выгрузка XML на сайт выполняется ТОЛЬКО при успешной сверке файлов.
2) После успешной выгрузки на сайт отправляется оповещение (по email) “тем же типом”, что и оповещение о сверке.

ВАЖНО
- Изменения делаются в обработке _РегистрацияФинансовыхПоказателейПоИИС (НЕ в “1”-версии).
- Для выгрузки на сайт используется внешняя обработка “ОтправкаДанныхПИФНаСайт” (создаётся через Обработки.ОтправкаДанныхПИФНаСайт.Создать()).

ШАГ 1. Ограничить выгрузку на сайт только успешной сверкой
Место: процедура ОтправитьОтчет(ПолучателиОповещения), блок #Область ПубликацияНаСайте

БЫЛО (примерно):
	#Область ПубликацияНаСайте
	Попытка
		ОтправитьXMLФайлыНаСайт(Вложения);
	Исключение
		// логирование/сообщение об ошибке
	КонецПопытки;
	#КонецОбласти

СТАЛО:
	#Область ПубликацияНаСайте
	Если СверкаФайловУспешна(РезультатСохранения, РезультатСверки) Тогда
		Попытка
			ПараметрыПодключения = ПолучитьПараметрыОтправкиНаСайт();
			ОтправитьXMLФайлыНаСайт(Вложения, ПараметрыПодключения);
			ОтправитьОповещениеОРазмещенииНаСайте(ПолучателиОповещения, Вложения, ПараметрыПодключения);
		Исключение
			Информация = ИнформацияОбОшибке();
			СообщитьПользователю(
				"РазмещениеДоходностиНаСайте",
				УровеньЖурналаРегистрации.Ошибка,
				"Ошибка отправки файлов доходности на сайт:" + Символы.ПС + ПодробноеПредставлениеОшибки(Информация));
		КонецПопытки;
	КонецЕсли;
	#КонецОбласти

Смысл:
- Если есть хотя бы 1 ошибка сохранения или хотя бы 1 расхождение — выгрузка на сайт НЕ выполняется.
- Если выгрузка прошла успешно — отправляем оповещение о размещении.

ШАГ 2. Добавить функции контроля “успешной сверки” и оповещения о размещении
Место: ниже процедуры ОтправитьОповещениеОРасхождениях (или рядом с блоком публикации на сайт).

Добавить область:

	#Область РазмещениеНаСайтеИОповещения

	Функция СверкаФайловУспешна(РезультатСохранения, РезультатСверки)
		Если РезультатСохранения <> Неопределено Тогда
			Для Каждого СтрокаСохранения Из РезультатСохранения Цикл
				Если Не СтрокаСохранения.Успешно Тогда
					Возврат Ложь;
				КонецЕсли;
			КонецЦикла;
		КонецЕсли;

		Если РезультатСверки <> Неопределено Тогда
			Для Каждого СтрокаСверки Из РезультатСверки Цикл
				Если СтрокаСверки.ЕстьРасхождения Тогда
					Возврат Ложь;
				КонецЕсли;
			КонецЦикла;
		КонецЕсли;

		Возврат Истина;
	КонецФункции

	Процедура ОтправитьОповещениеОРазмещенииНаСайте(ПолучателиОповещения, Вложения, ПараметрыПодключения)
		Если ПустаяСтрока(ПолучателиОповещения) Тогда
			Возврат;
		КонецЕсли;

		ТекстПисьма = "";
		НомерСтроки = 0;
		Для Каждого ЭлементВложения Из Вложения Цикл
			НомерСтроки = НомерСтроки + 1;
			ИмяФайла = ЭлементВложения.Ключ;
			ИмяСтратегии = СтрЗаменить(ИмяФайла, ".xml", "");
			ТекстПисьма = ТекстПисьма
				+ Строка(НомерСтроки) + ". " + ИмяСтратегии + Символы.ПС
				+ "Параметр ""ТекущийКаталог"" из параметров подключения: " + ПараметрыПодключения.ТекущийКаталог
				+ Символы.ПС + Символы.ПС;
		КонецЦикла;

		Если ПустаяСтрока(ТекстПисьма) Тогда
			Возврат;
		КонецЕсли;

		ТемаПисьма = "РЕГИОН ЭсМ. Размещение доходности ИИС на сайте на " + Формат(ЭтотОбъект.Период, "ДФ=dd.MM.yy");
		ПараметрыПисьма = Новый Структура(
			"Кому, Тема, Тело, ТипТекста",
			ПолучателиОповещения,
			ТемаПисьма,
			ТекстПисьма,
			ТипТекстаПочтовогоСообщения.ПроизвольныйТекст);

		РаботаСЭлектроннойПочтой.ОтправитьЭлектронноеПисьмо(
			РаботаСЭлектроннойПочтой.ПолучитьСистемнуюУчетнуюЗапись(),
			ПараметрыПисьма);
	КонецПроцедуры

	#КонецОбласти

Смысл:
- Формируем текст оповещения “по строкам стратегий” и добавляем “ТекущийКаталог”.
- Тип текста письма — ПроизвольныйТекст, как и в ОтправитьОповещениеОРасхождениях().

ШАГ 4. Исправить получение параметров выгрузки (критично)

ПРОБЛЕМА:
В функции ПолучитьПараметрыОтправкиНаСайт() часто встречается обращение к переменной Организация,
которая в модуле не определена. Это приводит к ошибке при вызове.

НУЖНО:
Заменить Организация на ЭтотОбъект.Организация в 3 местах:
1) ЗначениеДополнительнойНастройки(..., "_ПараметрыОтправкиДанныхПИФНаСайт", ...)
2) ЗначениеДополнительнойНастройки(..., "_ПараметрыОтправкиДанныхПИФНаСайтКлюч", ...)
3) текст предупреждения “Для организации ... не заданы параметры ...”

И ДОБАВИТЬ:
В конце функции, если параметры не заданы, сделать явный возврат:
	Возврат Неопределено;

----------------------------------------------------------------------------------------------------
ПРОВЕРКА (быстрый чек-лист)
1) Сверка нашла расхождения → на сайт НЕ выгружается, письмо о расхождениях отправляется.
2) Сверка без расхождений и сохранение без ошибок → на сайт выгружается, отправляется письмо об успешном размещении.
3) Если не заданы параметры выгрузки на сайт → публикация пропускается (без падения), показывается предупреждение.
