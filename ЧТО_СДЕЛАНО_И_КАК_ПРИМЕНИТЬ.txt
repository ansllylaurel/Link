ЧАСТЬ 1. КАК ПРИМЕНИТЬ ИЗМЕНЕНИЯ В 1С
================================================================================

Нужно скопировать содержимое двух файлов в модули форм в конфигураторе.

ФАЙЛ 1 → Форма "Основная"
Путь к файлу на диске:
  DataProcessors\СводноеПогашениеКупона\Forms\Основная\Ext\Form\Module.bsl

Что делать в конфигураторе:
  1. Открыть: Обработки → СводноеПогашениеКупона → Формы → Основная
  2. Двойной щелчок по форме → откроется дизайнер
  3. Кнопка "Модуль" или вкладка "Модуль"
  4. Ctrl+A (выделить всё) → Delete
  5. Вставить содержимое файла Module.bsl
  6. Ctrl+S (сохранить)

ФАЙЛ 2 → Форма "СозданиеПогашенийКупона"
Путь к файлу на диске:
  DataProcessors\СводноеПогашениеКупона\Forms\СозданиеПогашенийКупона\Ext\Form\Module.bsl

Что делать в конфигураторе:
  1. Открыть: Обработки → СводноеПогашениеКупона → Формы → СозданиеПогашенийКупона
  2. Двойной щелчок → откроется дизайнер
  3. Кнопка "Модуль"
  4. Ctrl+A → Delete
  5. Вставить содержимое файла Module.bsl
  6. Ctrl+S

ПОСЛЕ ОБОИХ ФАЙЛОВ:
  7. F7 (Обновить конфигурацию базы данных) → ОК

ИЗМЕНЕНИЕ 1 — Функция ЗаполнитьПлановыеПогашенияНаСервере
  Проблема: "Сумма купона в рублях" не заполнялась в таблице плановых погашений
  
  1а. В тексте SQL запроса (последний SELECT), после строки с СуммаКупона,
      добавлена строка расчёта суммы в рублях:
  
  БЫЛО (одна строка):
    |	СУММА(...) * &СуммаНаОднуОблигацию КАК СуммаКупона
    |ИЗ
  
  СТАЛО (две строки):
    |	СУММА(...) * &СуммаНаОднуОблигацию КАК СуммаКупона,
    |	СУММА(...) * &СуммаНаОднуОблигациюВРублях КАК СуммаКупонаВРублях
    |ИЗ
  
  1б. После строки УстановитьПараметр("СуммаНаОднуОблигацию"...)
      добавлена ещё одна строка установки параметра:
  
  БЫЛО:
    Запрос.УстановитьПараметр("СуммаНаОднуОблигацию", ЭтаФорма.СуммаНаОднуОблигацию);
    ПлановыеПогашения = Запрос.Выполнить().Выгрузить();
  
  СТАЛО:
    Запрос.УстановитьПараметр("СуммаНаОднуОблигацию", ЭтаФорма.СуммаНаОднуОблигацию);
    Запрос.УстановитьПараметр("СуммаНаОднуОблигациюВРублях", ЭтаФорма.СуммаНаОднуОблигациюВРублях);

ИЗМЕНЕНИЕ 4 — Процедура СуммаНаОднуОблигациюПриИзменении
  Проблема: при ручном изменении суммы на одну облигацию,
           сумма в рублях в плановых погашениях не пересчитывалась
  
  В цикл добавлена одна строка:
  
  БЫЛО:
    Для каждого СтрокаПогашенияПлановые Из ЭтаФорма.ПогашенияПлановые Цикл
        СтрокаПогашенияПлановые.СуммаКупона = СтрокаПогашенияПлановые.Количество * ЭтаФорма.СуммаНаОднуОблигацию;
    КонецЦикла;
  
  СТАЛО:
    Для каждого СтрокаПогашенияПлановые Из ЭтаФорма.ПогашенияПлановые Цикл
        СтрокаПогашенияПлановые.СуммаКупона = СтрокаПогашенияПлановые.Количество * ЭтаФорма.СуммаНаОднуОблигацию;
        СтрокаПогашенияПлановые.СуммаКупонаВРублях = СтрокаПогашенияПлановые.Количество * ЭтаФорма.СуммаНаОднуОблигациюВРублях;
    КонецЦикла;

  Проблема: поле "в т.ч. RUB" не заполнялось при открытии формы
           (заполнялось только после ввода расчетного счета)
  
  После строки "ЗначениеВРеквизитФормы(ТаблицаДанных, "ПогашенияКупона");"
  добавлен блок:
  
  БЫЛО:
    ЗначениеВРеквизитФормы(ТаблицаДанных, "ПогашенияКупона");
    
    ОбновитьЗаголовокСуммаНаОднуОблигацию();
  
  СТАЛО:
    ЗначениеВРеквизитФормы(ТаблицаДанных, "ПогашенияКупона");
    
    Если Строка(ВалютаНоминала) <> "RUB" Тогда
        Для каждого Строка Из ПогашенияКупона Цикл
            Строка.СуммаКупонаВРублях = Строка.Количество * СуммаНаОднуОблигациюВРублях;
        КонецЦикла;
    КонецЕсли;
    
    ОбновитьЗаголовокСуммаНаОднуОблигацию();
