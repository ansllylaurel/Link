Удаление регистра голосований. Что делать в Конфигураторе.

Код копировать только в одном месте. Остальное - руками в дереве конфигурации.

============================================================
ШАГ 1. Скопировать код модуля документа
============================================================

Куда:
  Документы -> ОсуществлениеПраваГолосаПоЦеннымБумагам
  -> правой кнопкой -> Открыть модуль объекта

Что:
  Выделить ВЕСЬ текст модуля, удалить, вставить целиком из файла:

  Конфигурация\Documents\ОсуществлениеПраваГолосаПоЦеннымБумагам\Ext\ObjectModule.bsl

Сохранить модуль.

Что изменилось в этом коде (чтобы свериться глазами):
  - нет процедуры ОбработкаПроведения
  - нет процедуры СформироватьДвиженияПоГолосованиям
  - запрос в ПредупредитьОДубляхГолосований идет
    к Документ.ОсуществлениеПраваГолосаПоЦеннымБумагам.Клиенты
    (раньше был РегистрСведений.ГолосованияНаСобранияхВладельцевЦенныхБумаг)

Модуль формы документа НЕ трогать.

============================================================
ШАГ 2. Отключить проведение документа
============================================================

Куда:
  Документы -> ОсуществлениеПраваГолосаПоЦеннымБумагам -> открыть свойства

Что:
  Закладка "Проведение"
  - Проведение: Запретить
  - Движения (регистры): список должен стать пустым
    Если там еще висит "ГолосованияНаСобранияхВладельцевЦенныхБумаг" - убрать.

Сохранить.

============================================================
ШАГ 3. Удалить регистр
============================================================

Куда:
  Регистры сведений -> ГолосованияНаСобранияхВладельцевЦенныхБумаг

Что:
  Правой кнопкой -> Удалить.

Конфигуратор спросит про зависимые объекты. Подтвердить удаление везде,
где фигурирует этот регистр. Сам документ НЕ удалять.

После этого Конфигуратор сам уберет регистр:
  - из ролей
  - из подсистемы "Бэк-офис УК -> Ценные бумаги"
  - из общего списка объектов

Права на сам документ ОсуществлениеПраваГолосаПоЦеннымБумагам не трогать.

============================================================
ШАГ 4. Проверить
============================================================

1. Глобальный поиск по конфигурации (Ctrl+Shift+F):
   ГолосованияНаСобранияхВладельцевЦенныхБумаг
   Результат должен быть пустым.

2. В подсистеме "Ценные бумаги" должен остаться только документ,
   регистра там быть не должно.

3. Обновить конфигурацию БД (F7).
   Если есть проведенные документы голосования - платформа спросит,
   что делать с движениями удаляемого регистра. Удалить движения.

Готово.
