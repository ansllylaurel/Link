===============================================================================
ИНСТРУКЦИЯ ПО ВНЕСЕНИЮ ИЗМЕНЕНИЙ В ОТЧЁТ "Отчет по портфелю (Группа Будущее)"
===============================================================================

Назначение правок:
    Исправить отражение денежных средств по р/счетам при наличии МНО
    в выгрузке CSV.

    После правок для каждого р/счёта в выгрузке будет две строки:
      1) "Денежные средства на расчетных счетах" — остаток НЕ размещённых
         в МНО денег.
      2) "Денежные средства МНО" — сумма МНО с указанием срока и ставки.
    В сумме эти две строки дают фактический остаток по р/счёту.

-------------------------------------------------------------------------------
ЧТО ПРАВИМ
-------------------------------------------------------------------------------

Правки вносятся ТОЛЬКО в один файл — схему компоновки данных отчёта:

    _ОтчетПоПортфелю_ГруппаБудущее
        -> Макеты
            -> ОсновнаяСхемаКомпоновкиДанных

(В выгруженной внешней обработке *.epf это файл:
    _ОтчетПоПортфелю_ГруппаБудущее\Templates\
    ОсновнаяСхемаКомпоновкиДанных\Ext\Template.xml)

Обе правки делаются в тексте запроса набора данных "НаборДанных1"
(редактируется в конструкторе запроса СКД на вкладке "Запрос").

Модуль объекта обработки (ObjectModule.bsl) и форму отчёта править НЕ НУЖНО.

-------------------------------------------------------------------------------
ПРАВКА № 1. Устранение задваивания строк МНО
-------------------------------------------------------------------------------

Где:
    В запросе набора данных, в пакете, где формируется временная таблица
    _ПрочиеАктивыРазвернуто (запрос к регистру сведений
    "СтоимостьАктивовНеОтносящихсяКЦеннымБумагам").

    Найти секцию "ГДЕ" этого запроса — она расположена непосредственно
    ПЕРЕД строкой "ОБЪЕДИНИТЬ ВСЕ", за которой идёт подзапрос из _ОстаткиМНО.

Что сделать:
    В секции ГДЕ добавить ОДНУ новую строку условия — последнюю, перед
    пустой строкой и "ОБЪЕДИНИТЬ ВСЕ".

    БЫЛО:
    --------------------------------------------------------------------
    ГДЕ
        СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.Период = &Период
        И СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.Организация = &Организация
        И СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.СчетДоверительногоУправления В
                (ВЫБРАТЬ
                    _СчетаДоверительногоУправления.СчетДоверительногоУправления
                ИЗ
                    _СчетаДоверительногоУправления)

    ОБЪЕДИНИТЬ ВСЕ

    ВЫБРАТЬ
        "МНО",
        _ОстаткиМНО.МНО,
        ...
    --------------------------------------------------------------------

    СТАЛО (добавлена строка с "ТИПЗНАЧЕНИЯ ... <> ТИП(Документ.МНО)"):
    --------------------------------------------------------------------
    ГДЕ
        СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.Период = &Период
        И СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.Организация = &Организация
        И СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.СчетДоверительногоУправления В
                (ВЫБРАТЬ
                    _СчетаДоверительногоУправления.СчетДоверительногоУправления
                ИЗ
                    _СчетаДоверительногоУправления)
        И ТИПЗНАЧЕНИЯ(СтоимостьАктивовНеОтносящихсяКЦеннымБумагам.СубъектАналитики) <> ТИП(Документ.МНО)

    ОБЪЕДИНИТЬ ВСЕ

    ВЫБРАТЬ
        "МНО",
        _ОстаткиМНО.МНО,
        ...
    --------------------------------------------------------------------

Зачем:
    Регистр сведений "СтоимостьАктивовНеОтносящихсяКЦеннымБумагам" уже
    содержит записи по МНО (с СубъектАналитики = Документ.МНО, см. документ
    "РегистрацияСтоимостиАктивов"). Одновременно МНО добавляется ещё раз
    ниже через "ОБЪЕДИНИТЬ ВСЕ ... _ОстаткиМНО" (из
    РегистрНакопления.ДенежныеСредстваМНО). Без этого фильтра МНО попадает
    в выгрузку два раза.

    Добавляемое условие исключает МНО из основной выборки; все данные по
    МНО остаются и берутся из единственного источника — регистра
    "ДенежныеСредстваМНО".

-------------------------------------------------------------------------------
ПРАВКА № 2. Переименование типа актива "МНО" в "Денежные средства МНО"
-------------------------------------------------------------------------------

Где:
    В том же запросе набора данных, в пакете, где формируется временная
    таблица _ОбщаяТаблица, во втором "ОБЪЕДИНИТЬ ВСЕ" — том, где соединение
    идёт с _ПрочиеАктивы (секция с CASE, определяющим значение "ТипАктива"
    для записей прочих активов: "Денежные средства на расчетных счетах",
    "Денежные средства на брокерских счетах", "Дебиторская задолженность
    по РЕПО" и т. п.).

Что сделать:
    Найти ветку CASE с проверкой "_ПрочиеАктивы.ВидАктива = "МНО""
    и изменить возвращаемое текстовое значение.

    БЫЛО:
    --------------------------------------------------------------------
        КОГДА _ПрочиеАктивы.ВидАктива = "МНО"
            ТОГДА "МНО"
    --------------------------------------------------------------------

    СТАЛО:
    --------------------------------------------------------------------
        КОГДА _ПрочиеАктивы.ВидАктива = "МНО"
            ТОГДА "Денежные средства МНО"
    --------------------------------------------------------------------

    Саму строку "КОГДА _ПрочиеАктивы.ВидАктива = "МНО"" НЕ менять —
    меняется только ТОГДА-часть, со строки "МНО" на "Денежные средства МНО".

Зачем:
    По ТЗ тип актива для МНО в CSV должен называться "Денежные средства МНО"
    (а не просто "МНО"), чтобы в колонке "Тип актива" были парные значения:
        - "Денежные средства на расчетных счетах" — не размещённый остаток;
        - "Денежные средства МНО" — размещённая в МНО сумма.

-------------------------------------------------------------------------------
ЧТО ПРОВЕРИТЬ ПОСЛЕ ПРАВОК
-------------------------------------------------------------------------------

1. Сформировать отчёт в режиме CSV по счёту ДУ, у которого есть МНО.
2. В файле CSV по каждому р/счёту должно присутствовать ДВЕ строки:
       Тип актива = "Денежные средства на расчетных счетах" — сумма = остаток
                    по р/с БЕЗ размещённой в МНО части;
       Тип актива = "Денежные средства МНО"                 — по одной строке
                    на каждое действующее МНО, с заполненными полями
                    "Дата погашения депозита" (дата возврата МНО),
                    "Текущая процентная ставка по депозиту" (процент МНО),
                    "Вид процентной ставки по депозиту" = "С выплатой в конце срока".
3. Сумма строк "Денежные средства на расчетных счетах" и "Денежные средства МНО"
   по одному р/счёту должна совпадать с фактическим остатком по этому р/счёту
   на дату отчёта.
4. Если МНО на р/счёте нет — выгрузка не должна измениться по сравнению
   с предыдущей версией.
5. Убедиться, что строки МНО не задваиваются.

-------------------------------------------------------------------------------
ВЕРСИЯ ОБРАБОТКИ
-------------------------------------------------------------------------------

После внесения изменений поднять версию в модуле объекта обработки:
    Функция СведенияОВнешнейОбработке()
        ... "0.24" -> "0.25" ...
(необязательно, но рекомендуется — чтобы отличать доработанную версию).
