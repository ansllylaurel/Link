Изменение 1. Заполнение суммы в рублях для плановых погашений
--------------------------------------------------------------------------------
Где найти: Модуль формы "Основная", процедура называется "ЗаполнитьПлановыеПогашенияНаСервере".
Что изменено: В текст запроса добавлено вычисление поля "СуммаКупонаВРублях", а также добавлена передача параметра "СуммаНаОднуОблигациюВРублях" в запрос.

Код ДО (фрагмент текста запроса в конце):
		|	СУММА(ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоВРЕПО, 0)) КАК КоличествоВРЕПО,
		|	СУММА(ЕСТЬNULL(ОстаткиЦенныхБумагОстатки.КоличествоОстаток, ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоПоРЕПО, 0)) + ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоВРЕПО, 0)) * &СуммаНаОднуОблигацию КАК СуммаКупона
		|ИЗ

Код ПОСЛЕ (фрагмент текста запроса в конце):
		|	СУММА(ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоВРЕПО, 0)) КАК КоличествоВРЕПО,
		|	СУММА(ЕСТЬNULL(ОстаткиЦенныхБумагОстатки.КоличествоОстаток, ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоПоРЕПО, 0)) + ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоВРЕПО, 0)) * &СуммаНаОднуОблигацию КАК СуммаКупона,
		|	СУММА(ЕСТЬNULL(ОстаткиЦенныхБумагОстатки.КоличествоОстаток, ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоПоРЕПО, 0)) + ЕСТЬNULL(_ЦенныеБумагиВРЕПО.КоличествоВРЕПО, 0)) * &СуммаНаОднуОблигациюВРублях КАК СуммаКупонаВРублях
		|ИЗ

Код ДО (фрагмент установки параметров ниже по коду):
	Запрос.УстановитьПараметр("ВидыЗадолженности"	, ВидыЗадолженностиПоРЕПО);
	Запрос.УстановитьПараметр("СуммаНаОднуОблигацию", ЭтаФорма.СуммаНаОднуОблигацию);
	
	ПлановыеПогашения = Запрос.Выполнить().Выгрузить();

Код ПОСЛЕ (фрагмент установки параметров ниже по коду):
	Запрос.УстановитьПараметр("ВидыЗадолженности"	, ВидыЗадолженностиПоРЕПО);
	Запрос.УстановитьПараметр("СуммаНаОднуОблигацию", ЭтаФорма.СуммаНаОднуОблигацию);
	Запрос.УстановитьПараметр("СуммаНаОднуОблигациюВРублях", ЭтаФорма.СуммаНаОднуОблигациюВРублях);
	
	ПлановыеПогашения = Запрос.Выполнить().Выгрузить();

Изменение 2. Пересчет суммы в рублях при ручном изменении суммы на 1 облигацию
--------------------------------------------------------------------------------
Где найти: Модуль формы "Основная", процедура называется "СуммаНаОднуОблигациюПриИзменении".
Что изменено: Добавлен пересчет колонки "СуммаКупонаВРублях" в цикле обхода плановых погашений.

Код ДО (целиком процедура):
&НаКлиенте
Процедура СуммаНаОднуОблигациюПриИзменении(Элемент)
	
	Для каждого СтрокаПогашенияПлановые Из ЭтаФорма.ПогашенияПлановые Цикл
		СтрокаПогашенияПлановые.СуммаКупона = СтрокаПогашенияПлановые.Количество * ЭтаФорма.СуммаНаОднуОблигацию;
	КонецЦикла;
	
	ОбновитьНадписьПогашенияПлановыеИтого(ЭтаФорма);
	
КонецПроцедуры

Код ПОСЛЕ (целиком процедура):
&НаКлиенте
Процедура СуммаНаОднуОблигациюПриИзменении(Элемент)
	
	Для каждого СтрокаПогашенияПлановые Из ЭтаФорма.ПогашенияПлановые Цикл
		СтрокаПогашенияПлановые.СуммаКупона = СтрокаПогашенияПлановые.Количество * ЭтаФорма.СуммаНаОднуОблигацию;
		СтрокаПогашенияПлановые.СуммаКупонаВРублях = СтрокаПогашенияПлановые.Количество * ЭтаФорма.СуммаНаОднуОблигациюВРублях;
	КонецЦикла;
	
	ОбновитьНадписьПогашенияПлановыеИтого(ЭтаФорма);
	
КонецПроцедуры

Изменение 4. Динамический заголовок для плановых погашений
--------------------------------------------------------------------------------
Где найти: Модуль формы "Основная", процедура называется "ОбновитьЗаголовокСуммаНаОднуОблигацию".
Что изменено: Добавлено обновление заголовка колонки суммы для таблицы плановых погашений.

Код ДО (целиком процедура):
&НаСервере
Процедура ОбновитьЗаголовокСуммаНаОднуОблигацию()

	Заголовок = "Сумма на одну облигацию";
	ПоказатьВРублях = Ложь;

	Если ЗначениеЗаполнено(ВалютаНоминала) Тогда
		Заголовок = Заголовок + " в " + Строка(ВалютаНоминала);
		ПоказатьВРублях = (Строка(ВалютаНоминала) <> "RUB");
	КонецЕсли;

	Элементы.СуммаНаОднуОблигацию.Заголовок = Заголовок;
	Элементы.СуммаНаОднуОблигациюВРублях.Видимость = ПоказатьВРублях;

	ЗаголовокСуммаКупона = "Сумма купона";
	Если ЗначениеЗаполнено(ВалютаНоминала) Тогда
		ЗаголовокСуммаКупона = ЗаголовокСуммаКупона + " в " + Строка(ВалютаНоминала);
	КонецЕсли;
	Элементы.ПогашенияСозданныеГруппаСуммаКупона.Заголовок = ЗаголовокСуммаКупона;

КонецПроцедуры

Код ПОСЛЕ (целиком процедура):

Изменение 5. Расчет суммы в рублях при открытии формы
--------------------------------------------------------------------------------
Где найти: Модуль формы "СозданиеПогашенийКупона", процедура называется "ПриСозданииНаСервере".
Что изменено: Добавлен цикл, который рассчитывает сумму в рублях после того, как таблица заполняется из регистра настроек.

Код ДО (фрагмент в конце процедуры):
	ТаблицаДанных = РегистрыСведений.НастройкиУчетаДоходовПоЦеннымБумагам.ПолучитьЗначенияНастроекУчетаДоходовПоЦеннымБумагам(РеквизитФормыВЗначение("ПогашенияКупона"), ЭтаФорма.Дата, ЭтаФорма.Организация);
	
	ЗначениеВРеквизитФормы(ТаблицаДанных, "ПогашенияКупона");
	
	ОбновитьЗаголовокСуммаНаОднуОблигацию();
	
	ОбновитьНадписьПогашенияКупонаИтого(ЭтаФорма);
	
КонецПроцедуры

Код ПОСЛЕ (фрагмент в конце процедуры):
	ТаблицаДанных = РегистрыСведений.НастройкиУчетаДоходовПоЦеннымБумагам.ПолучитьЗначенияНастроекУчетаДоходовПоЦеннымБумагам(РеквизитФормыВЗначение("ПогашенияКупона"), ЭтаФорма.Дата, ЭтаФорма.Организация);
	
	ЗначениеВРеквизитФормы(ТаблицаДанных, "ПогашенияКупона");
	
	Если Строка(ВалютаНоминала) <> "RUB" Тогда
		Для каждого Строка Из ПогашенияКупона Цикл
			Строка.СуммаКупонаВРублях = Строка.Количество * СуммаНаОднуОблигациюВРублях;
		КонецЦикла;
	КонецЕсли;
	
	ОбновитьЗаголовокСуммаНаОднуОблигацию();
	
	ОбновитьНадписьПогашенияКупонаИтого(ЭтаФорма);
	
КонецПроцедуры
