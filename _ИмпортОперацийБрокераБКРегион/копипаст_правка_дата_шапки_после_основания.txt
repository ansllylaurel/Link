ПРАВКА ДЛЯ РУЧНОГО ВНЕСЕНИЯ В БАЗУ: дата документа «Оплата» после выбора основания (в т.ч. Альт)
============================================================================================

Обработка: _ИмпортОперацийБрокераБКРегион
Модуль объекта, функция: ОбработатьОплатыПоПогашениям_OTBR
Место: цикл Пока Выборка.Следующий() Цикл

Зачем: если основание подставляется через ветку ОснованиеАльт, дата шапки должна считаться
по финальному РеквизитыОснования.Основание, а не по пустому Выборка.Основание.


--------------------------------------------------------------------------------
ЗАМЕНА 1 из 2 — начало заполнения РеквизитыШапки (убрать строку Дата отсюда)
--------------------------------------------------------------------------------

Найдите фрагмент сразу после создания структуры шапки (после Новый Структура(ПоляДокумента.Шапка)).

----- БЫЛО -----

		РеквизитыШапки = Новый Структура(ПоляДокумента.Шапка);
		РеквизитыШапки.Проведен                     = Истина;
		РеквизитыШапки.ПометкаУдаления              = Ложь;
		РеквизитыШапки.Дата                         = ?(ЗначениеЗаполнено(Выборка.Основание) И НачалоДня(Выборка.Основание.Дата) = ЭтотОбъект.ДатаИмпорта, Выборка.Основание.Дата + 1, ЭтотОбъект.ДатаИмпорта + (9 * 60 + 30) * 60); //"9:30:00"
		РеквизитыШапки.Организация                  = ЭтотОбъект.Организация;

----- СТАЛО -----

		РеквизитыШапки = Новый Структура(ПоляДокумента.Шапка);
		РеквизитыШапки.Проведен                     = Истина;
		РеквизитыШапки.ПометкаУдаления              = Ложь;
		РеквизитыШапки.Организация                  = ЭтотОбъект.Организация;


--------------------------------------------------------------------------------
ЗАМЕНА 2 из 2 — после блока Если/Иначе по основанию (вставить расчёт Дата)
--------------------------------------------------------------------------------

Найдите конец большого условия по Выборка.Основание / ОснованиеАльт / ошибкам —
это три подряд идущих «КонецЕсли;», после которых сразу идёт заполнение Ключа строки операции:

		КонецЕсли;
		КонецЕсли;
		КонецЕсли;
		
		НоваяСтрокаОперации.Ключ         = ...

Между последним «КонецЕсли;» (закрывающим внешний Если ЗначениеЗаполнено(Выборка.Основание))
и строкой «НоваяСтрокаОперации.Ключ» должно быть следующее.

----- БЫЛО (там сейчас пустая строка или сразу Ключ) -----

		КонецЕсли;
		
		НоваяСтрокаОперации.Ключ         = ВидЗадолженностиОперации.ИмяПредопределенныхДанных + ...

----- СТАЛО -----

		КонецЕсли;
		
		// Дата считается здесь — после того, как определено финальное основание (первичное или альтернативное)
		РеквизитыШапки.Дата = ?(ЗначениеЗаполнено(РеквизитыОснования.Основание) И НачалоДня(РеквизитыОснования.Основание.Дата) = ЭтотОбъект.ДатаИмпорта, РеквизитыОснования.Основание.Дата + 1, ЭтотОбъект.ДатаИмпорта + (9 * 60 + 30) * 60); //"9:30:00"
		
		НоваяСтрокаОперации.Ключ         = ВидЗадолженностиОперации.ИмяПредопределенныхДанных + ...
(остальная часть строки Ключ без изменений)

Остальные правки (оферта, _ПогашенияВДень, запрос _ОплатыПоПогашениямВнешниеДанные, цикл Альт)
================================================================================
