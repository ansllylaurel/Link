Использование параметров
ПараметрыМодуля - Структура, где ключ - имя параметра.
Доступность:
Клиент, сервер.
Пример:
Ссылка = ПараметрыМодуля.Ссылка;

Просмотр коллекций
Для вывода универсальных коллекций можно воспользоваться процедурой ВывестиКоллекцию(<Коллекция>, <ВыводитьТипыЗначений>, <НаименованиеКоллекции>) .
Параметры:
<Коллекция>  (обязательный) - ТаблицаЗначений, СписокЗначений, Массив, Структура, Соответствие и их фиксированные варианты
<ВыводитьТипыЗначений> (необязательный) - Булево. Значение по умолчанию - Истина. При выводе таблицы значений данный параметр игнорируется
<НаименованиеКоллекции> (необязательный) - Строка. Значение по умолчанию - представление типа коллекции.
Доступность:
Сервер.
Пример:
ВывестиКоллекцию(Структура);

Использование процедур и функций:
На закладке Процедуры и функции можно ввести текст внешнего модуля, содержащего процедуры и функции. Для того, чтобы методы, объявленные во внешнем модуле, были доступны из данной обработки, они должны быть объявлены с ключевым словом Экспорт
Доступность:
Сервер.
Пример:
Результат = ВнешнийМодуль.ПолучитьРезультатРасчета(ПараметрыРасчета);

Вывод табличных документов с сервера:
Возможна ситуация, при которой необходимо вывести на экран табличный документ, сформированный на сервере. Так как метод табличного документа Показать() доступен только на клиенте, можно добавить сформированный табличный документ в предопределенный список значений _МассивТаблицЗначенийДляВывода.
После того как отработает код модуля на сервере, будет выполнен вывод всех табличных документов из данного списка.
Доступность:
Сервер.
Пример:
_МассивТаблицЗначенийДляВывода.Добавить(ТабДок);
