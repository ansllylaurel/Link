# Спецификация: добавление статистики работы внутренних механизмов

ЗАДАЧА: в указанном файле(ах) `Module.bsl` модуля формы обработки 1С (BSL, код на русском) обернуть все клиентские команды регистрацией статистики и добавить служебную область.

## КРИТИЧЕСКИ ВАЖНО
- Редактируй ТОЛЬКО указанные файлы (они в папке `Конфигурация\DataProcessors`).
- НИКОГДА не открывай, не читай, не копируй из папки `DataProcessors (сломанные)` — там всё неправильно. Даже не заглядывай туда.
- Не меняй структуру модуля (порядок процедур, области), кроме выноса тела команды в хелпер.
- Не трогай `ObjectModule.bsl`.

## Что считается командой
Процедура с заголовком `&НаКлиенте Процедура ИмяКоманды(Команда)` — единственный параметр `Команда`. Только такие оборачиваем. Обработчики событий элементов (параметры `Элемент` и т.п.) НЕ трогаем.

## Правила оборачивания

### Вариант 1 — тело команды состоит из ОДНОГО вызова (одна инструкция)
Оборачиваем прямо:
```
&НаКлиенте
Процедура ИмяКоманды(Команда)
	
	ПараметрыСессии = ЗарегистрироватьНовуюСессию("ИмяКоманды");
	Попытка
		<единственный вызов>;
	Исключение
		ПараметрыСессии.ТекстОшибки = ПодробноеПредставлениеОшибки(ИнформацияОбОшибке());
		ЗарегистрироватьОкончаниеСессии(ПараметрыСессии);
		Возврат;
	КонецПопытки;
	ЗарегистрироватьОкончаниеСессии(ПараметрыСессии);
	
КонецПроцедуры
```

### Вариант 2 — тело команды из НЕСКОЛЬКИХ инструкций
Выносим ВСЁ тело в новый хелпер `Выполнить<Имя>(ПараметрыСессии)`, размещаем его СРАЗУ после команды (тот же `&НаКлиенте`). В `Попытка` — строго ОДНА строка (вызов хелпера):
```
&НаКлиенте
Процедура ИмяКоманды(Команда)
	
	ПараметрыСессии = ЗарегистрироватьНовуюСессию("ИмяКоманды");
	Попытка
		ВыполнитьЧтоТо(ПараметрыСессии);
	Исключение
		ПараметрыСессии.ТекстОшибки = ПодробноеПредставлениеОшибки(ИнформацияОбОшибке());
		ЗарегистрироватьОкончаниеСессии(ПараметрыСессии);
		Возврат;
	КонецПопытки;
	ЗарегистрироватьОкончаниеСессии(ПараметрыСессии);
	
КонецПроцедуры

&НаКлиенте
Процедура ВыполнитьЧтоТо(ПараметрыСессии)
	
	<исходное тело команды>
	
КонецПроцедуры
```
- Имя хелпера: `Выполнить` + смысловая часть имени команды (например `КомандаСформировать` → `ВыполнитьФормирование`). Имя НЕ должно совпадать с уже существующей процедурой. НИКОГДА не создавай имя вида `ВыполнитьВыполнить`.
- Внутри хелпера МЯГКИЕ выходы (`Возврат` без исключения — например после `Предупреждение`/`ПредупреждениеАсинх` или проверки-выхода) ДОПОЛНЯЕМ строкой `ПараметрыСессии.ТекстОшибки = "<краткая причина>";` ПЕРЕД `Возврат;`. Логику не меняем.

### Общее правило
В `Попытка` ВСЕГДА ровно ОДНА строка. Никогда не оставляй несколько инструкций внутри `Попытка`.

## Область в конце модуля
Добавь в самый конец файла (РОВНО ОДИН РАЗ) ДОСЛОВНО:
```
#Область СтатистикаРаботыВнутреннихМеханизмов

&НаСервере
Функция ЗарегистрироватьНовуюСессию(ИмяКоманды)
	
	ОбъектОбработки = РеквизитФормыВЗначение("Объект");
	
	ПараметрыВыполненияДляСбораСтатистики = РегистрыСведений.СтатистикаРаботыВнутреннихМеханизмов.ПолучитьПараметрыВыполнения(ОбъектОбработки);
	
	Механизм = ОбъектОбработки.Метаданные().ПолноеИмя() + ":" + ИмяКоманды;
	Сессия   = РегистрыСведений.СтатистикаРаботыВнутреннихМеханизмов.ЗарегистрироватьНовуюСессию(
		Механизм,
		ПараметрыВыполненияДляСбораСтатистики.Хранилище,
		ПараметрыВыполненияДляСбораСтатистики.Описание);
		
	ПараметрыСессии = Новый Структура;
	ПараметрыСессии.Вставить("Механизм",     Механизм);
	ПараметрыСессии.Вставить("Сессия",        Сессия);
	ПараметрыСессии.Вставить("ДопПараметры",  Неопределено);
	ПараметрыСессии.Вставить("ТекстОшибки",   Неопределено);
		
	Возврат ПараметрыСессии;
	
КонецФункции

&НаСервереБезКонтекста
Процедура ЗарегистрироватьОкончаниеСессии(ПараметрыСессии)
	
	РегистрыСведений.СтатистикаРаботыВнутреннихМеханизмов.ЗарегистрироватьОкончаниеСессии(
		ПараметрыСессии.Механизм,
		ПараметрыСессии.Сессия,,
		ПараметрыСессии.ДопПараметры,
		ПараметрыСессии.ТекстОшибки);
	
КонецПроцедуры

#КонецОбласти
```
- В каждом файле формы — своя область (один раз на файл). Если область уже есть — не добавляй повторно.

## Самопроверка перед завершением
- Число `Процедура`/`Функция` = числу `КонецПроцедуры`/`КонецФункции`.
- Каждая команда `(Команда)` обёрнута; в её `Попытке` ровно одна строка.
- Нет двух процедур/функций с одинаковым именем (особенно нет `ВыполнитьВыполнить`).
- Область статистики добавлена один раз и компилируема.
- Запусти `ReadLints` по файлу — ошибок быть не должно.

## Отчёт
Верни кратко: путь файла, список обёрнутых команд, имена созданных хелперов, добавлена ли область, результат линта.
