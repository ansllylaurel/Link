Записи внутреннего учёта по клиентам (НАУФОР, п. 5)
=====================================================

Файл запроса: ЗаписиВнутреннегоУчета_НАУФОР.txt

Назначение
----------
Один пакетный запрос для выгрузки записей внутреннего учёта по сделкам клиентов
за период. Результат содержит 4 логические таблицы в одном наборе данных,
различаемые колонкой «Раздел»:

  • Сделки
  • Сделки РЕПО
  • МНО
  • Депозитные вклады

Логика построена на отчёте «Форма 482» (_ОтчетУправляющегоФорма482).

Параметры (задать в консоли запросов перед выполнением)
-------------------------------------------------------
  &Организация       — Справочник.Организации (управляющая компания)
  &НачалоПериода     — Дата, например 30.04.2024
  &КонецПериода      — Дата, например 26.05.2026
  &СписокКлиентов    — Массив ссылок:
                       Справочник.ЮрФизЛица и/или Справочник.ПаевыеИнвестиционныеФонды

Пример установки параметров в коде (перед выполнением в консоли):

  Запрос.УстановитьПараметр("Организация", Организация);
  Запрос.УстановитьПараметр("НачалоПериода", '20240430');
  Запрос.УстановитьПараметр("КонецПериода", '20260526');
  Запрос.УстановитьПараметр("СписокКлиентов", МассивКлиентов);

Порядок запуска
---------------
1. Открыть консоль запросов в 1С (УправлениеФинансовойОрганизацией).
2. Скопировать весь текст из файла ЗаписиВнутреннегоУчета_НАУФОР.txt.
3. Задать параметры &Организация, &НачалоПериода, &КонецПериода, &СписокКлиентов.
4. Выполнить запрос (один раз — все 4 раздела формируются пакетом).

Выгрузка в Excel (4 листа)
--------------------------
1. Результат → «Вывести в табличный документ» или «Выгрузить в Excel».
2. Сохранить как xlsx.
3. Разделить на 4 листа по фильтру колонки «Раздел»:
   — лист «Сделки»           → Раздел = «Сделки»
   — лист «Сделки РЕПО»      → Раздел = «Сделки РЕПО»
   — лист «МНО»              → Раздел = «МНО»
   — лист «Депозитные вклады»→ Раздел = «Депозитные вклады»

Колонки, не применимые к разделу, заполнены нулями или пустыми значениями —
при формировании листов их можно скрыть.
